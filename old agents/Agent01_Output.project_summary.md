## 项目概览

本项目是医疗建筑能源管理平台的CIM（计算无关模型）构建项目，专注于建立医疗建筑全专业的系统拓扑和依赖关系模型。作为模型驱动架构（MDA）的第一层，我们为医疗建筑技术系统提供了完整的数字化建模基础。

## 💡 关键技术亮点

### 🔧 统一的拓扑建模范式

**节点类型体系**：
- **源节点 (SOURCE)** - 能量/介质产生源，如冷水机组、变压器
- **分配节点 (DISTRIBUTION)** - 能量/介质分配枢纽，如分水器、配电柜
- **汇节点 (SINK)** - 终端使用设备，如空调机组、照明灯具

**边类型体系**：
- **主干边 (TRUNK)** - 高容量主传输路径
- **分支边 (BRANCH)** - 中等容量区域分配
- **终端边 (TERMINAL)** - 连接到最终使用设备

### 🏥 医疗场景专业化建模

**关键医疗空间建模深度**：
- 手术室洁净环境：ISO 5级，层流送风，0.25m/s面速
- ICU精密环境：ISO 7级，N+1冗余，±2°C温控精度
- 负压隔离病房：-30Pa压力梯度，99.97% HEPA过滤
- 医药存储区：多温区精准控制，7×24监测系统

**解析医疗法规要求**：
```
✓ GB 50751 医用气体工程技术规范
✓ IEC 60364-7-710 医疗场所电气安全
✓ GB 50016 建筑设计防火规范
✓ GB 50736 民用建筑供暖通风与空气调节设计规范
✓ GB/T 50314 智能建筑设计标准
```

### 🔄 系统依赖关系深度分析

**复杂依赖网络揭示**：
- 电力系统是所有系统的根本依赖（FUNDAMENTAL级别）
- 冷源系统直接影响7个下游系统的运行
- 火灾时系统依赖关系发生重组和切换
- 医疗系统要求更严格的可靠性冗余（N+1或2N配置）

**级联失效模型**：
```
触发源: 主电源中断 →
级联1: 制冷系统停机 →
级联2: 空调环境失效 →
终局: 手术室停用 + ICU环境恶化
防护措施: 柴油发电机, UPS, 备用冷源, 分区隔离
```
