# 计量体系

> 本文档介绍医疗建筑能源计量体系建模，包括计量层级、能源分类和能耗分摊（Agent-07专业领域）。

## 概述

能源计量是能耗管理的基础，目标是：
- **可测量**: 准确测量各类能源消耗
- **可分摊**: 将能耗分摊到各级空间
- **可分析**: 支持能效分析和优化

## 计量层级

```
L0: Site (站点)           ← 总表
    ↓
L1: Building (建筑)       ← 建筑总表
    ↓
L2: Floor (楼层)          ← 楼层分表
    ↓
L3: Zone (区域)           ← 区域计量
    ↓
L4: Room (房间)           ← 房间子表
    ↓
L5: Equipment (设备)      ← 设备计量
```

### 层级详解

```yaml
L0 - 站点级计量:
  目的: 了解医院总能耗
  计量点:
    - 总电表 (市政供电)
    - 总水表 (市政供水)
    - 总燃气表 (如果有锅炉)
  
L1 - 建筑级计量:
  目的: 了解各建筑能耗
  示例:
    - 门诊楼总表
    - 住院楼总表
    - 医技楼总表
  
L2 - 楼层级计量:
  目的: 了解各楼层能耗
  示例:
    - 门诊楼3层电表
    - 门诊楼3层水表
  
L3 - 区域级计量:
  目的: 了解功能区能耗
  示例:
    - 3层门诊医疗区电表
    - 3层候诊大厅电表
  
L4 - 房间级计量:
  目的: 了解具体房间能耗
  示例:
    - 诊室-301电表
    - 护士站电表
  
L5 - 设备级计量:
  目的: 了解关键设备能耗
  示例:
    - 冷水机组电表
    - 空调机组电表
```

## 能源分类

### 电能计量

```yaml
电能计量:
  计量单位: kWh (千瓦时)
  
  分项计量:
    - 暖通空调: 冷机、水泵、风机、末端
    - 照明插座: 一般照明、应急照明、插座
    - 动力设备: 电梯、水泵、风机
    - 特殊设备: 医疗设备、IT设备
    - 厨房餐饮: 厨房设备
  
  电力参数:
    - 电压 (V)
    - 电流 (A)
    - 有功功率 (kW)
    - 无功功率 (kvar)
    - 功率因数
    - 频率 (Hz)
```

### 水计量

```yaml
水计量:
  计量单位: m³ (立方米)
  
  分类计量:
    - 生活给水: 饮用水、生活用水
    - 热水: 生活热水、采暖热水
    - 冷却水: 补水量
    - 消防水: (单独计量)
    - 特殊水: 纯水、软化水
  
  参数:
    - 瞬时流量 (m³/h)
    - 累计流量 (m³)
    - 水温 (°C)
```

### 燃气计量

```yaml
燃气计量:
  计量单位: m³ (立方米) 或 GJ (吉焦)
  
  用途:
    - 锅炉供暖
    - 厨房餐饮
    - 生活热水
  
  参数:
    - 瞬时流量 (m³/h)
    - 累计流量 (m³)
    - 燃气压力 (kPa)
```

### 冷热量计量

```yaml
冷热量计量:
  计量单位: GJ (吉焦) 或 MWh (兆瓦时)
  
  计量方式:
    - 直接计量: 热量表
    - 间接计算: 流量 × 温差 × 系数
  
  公式:
    Q = ∫(m × ΔT × c)dt
    Q: 热量 (kJ)
    m: 质量流量 (kg/s)
    ΔT: 温差 (K)
    c: 比热容 (kJ/kg·K)
```

## 计量设备

### 智能电表

```yaml
智能电表:
  类型:
    - 三相四线制: 用于大功率设备
    - 单相: 用于照明、插座
  
  功能:
    - 正向/反向有功电能计量
    - 多费率计量 (峰平谷)
    - 实时参数测量
    - 通信接口 (RS485/MODBUS)
  
  精度: 0.5级或1.0级
  
  通信:
    - 数据采集器通过RS485读取
    - 上传至能源管理系统
```

### 超声波热量表

```yaml
超声波热量表:
  组成:
    - 流量计: 超声波原理
    - 温度传感器: 供回水温度
    - 积分仪: 计算热量
  
  适用:
    - 冷冻水系统
    - 热水系统
  
  精度: 2级或3级
```

### 水表

```yaml
智能水表:
  类型:
    - 机械式: 旋翼式、螺翼式
    - 超声波式: 无压损，精度高
    - 电磁式: 用于大管径
  
  功能:
    - 累计流量计量
    - 瞬时流量显示
    - 远传功能
```

## 能耗分摊规则

### 分摊方法

```yaml
按面积分摊:
  适用场景: 公共区域、基础照明
  公式: 
    房间分摊能耗 = 总能耗 × (房间面积 / 总面积)
  
  示例:
    3层总能耗: 10000 kWh
    总面积: 2000 m²
    ROOM-301 (20m²): 100 × 20/2000 = 100 kWh

按人员分摊:
  适用场景: 新风系统
  公式:
    房间分摊能耗 = 总能耗 × (房间人数 / 总人数)
  
  示例:
    新风系统能耗: 2000 kWh
    总人数: 100人
    ROOM-301 (4人): 2000 × 4/100 = 80 kWh

按负荷分摊:
  适用场景: 中央空调系统
  公式:
    房间分摊能耗 = 总能耗 × (房间负荷 / 总负荷)
  
  示例:
    空调系统能耗: 8000 kWh
    总冷负荷: 400 kW
    ROOM-301 (3.5kW): 8000 × 3.5/400 = 70 kWh

按使用时间分摊:
  适用场景: 设备用电
  公式:
    房间分摊能耗 = 总能耗 × (房间使用时长 / 总时长)
```

### 分摊示例

```yaml
场景: 门诊综合楼3层空调系统能耗分摊

系统信息:
  总电耗: 10000 kWh
  服务区域: 3层全部

Step 1: 按区域分摊
  内科诊区 (800m², 40%): 4000 kWh
  外科诊区 (600m², 30%): 3000 kWh
  候诊大厅 (600m², 30%): 3000 kWh

Step 2: 内科诊区内部分摊
  ROOM-301 (20m², 3.5kW负荷, 20人): 
    按面积: 4000 × 20/800 = 100 kWh
    按负荷: 4000 × 3.5/80 = 175 kWh
    取加权平均: 140 kWh

Step 3: 设备级分摊 (可选)
  FCU-301 (末端设备):
    运行时间: 10小时
    平均功率: 0.5 kW
    直接计量: 5 kWh
```

## 能效指标

### 建筑能效指标

```yaml
单位面积能耗:
  公式: 总能耗 / 建筑面积
  单位: kWh/m²·年
  
  参考值:
    一般医院: 150-250 kWh/m²·年
    节能医院: 100-150 kWh/m²·年

空调系统能效:
  制冷能效: 
    指标: SCOP (系统能效比)
    公式: 总制冷量 / 总耗电量
    参考值: > 3.5
  
  输送能效:
    冷冻水: < 0.5 kW/m³h
    冷却水: < 0.3 kW/m³h
    风系统: < 0.4 W/m³h

照明功率密度:
  公式: 照明功率 / 面积
  单位: W/m²
  
  参考值:
    诊室: ≤ 9 W/m²
    走廊: ≤ 5 W/m²
```

### 设备能效指标

```yaml
冷水机组:
  COP (能效比): 制冷量 / 耗电量
  参考值: 5.5-6.5
  
  IPLV (综合部分负荷性能):
  参考值: 6.0-7.0

水泵:
  效率: 输出水功率 / 输入电功率
  参考值: > 70%

风机:
  效率: 空气功率 / 输入电功率
  参考值: > 65%
```

## 计量数据应用

### 能耗分析

```yaml
同比分析:
  与去年同期对比
  消除季节影响

环比分析:
  与上月对比
  发现短期异常

对标分析:
  与同类建筑对比
  发现节能潜力

趋势分析:
  预测未来能耗
  制定节能目标
```

### 节能诊断

```yaml
异常检测:
  - 夜间非运营时段能耗异常
  - 节假日能耗异常
  - 单位面积能耗超标

诊断方法:
  - 能耗拆分分析
  - 能效指标计算
  - 对比基准值
```
