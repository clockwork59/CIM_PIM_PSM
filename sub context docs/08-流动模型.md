# 流动模型

> 本文档介绍医疗建筑物质流、能量流、信息流的三流合一模型（Agent-04专业领域）。

## 概述

医疗建筑中的机电系统本质上是处理各种"流动"的系统。CIM流动模型通过统一的框架描述：
- **物质流**：水、空气、气体、蒸汽
- **能量流**：冷热能量、电能、机械能
- **信息流**：控制信号、传感器数据、状态反馈

## 三层流动模型

```
┌─────────────────────────────────────────┐
│  Layer 1: 物质流 (Mass Flow)            │
│  水、空气、气体、蒸汽                     │
├─────────────────────────────────────────┤
│  Layer 2: 能量流 (Energy Flow)          │
│  冷热能量、电能、机械能                   │
├─────────────────────────────────────────┤
│  Layer 3: 信息流 (Information Flow)     │
│  控制信号、传感器数据、状态信息           │
└─────────────────────────────────────────┘
```

## 物质流 (Mass Flow)

### 水流

**冷冻水 (CHW - Chilled Water)**
```yaml
流动路径: 冷水机组蒸发器 → 冷冻水泵 → 分水器 → 支管 → 末端设备 → 集水器 → 返回冷机
温度参数:
  供水: 7°C
  回水: 12°C
  温差: 5K
压力参数:
  工作压力: 1.0 MPa
流量参数:
  设计流量: 180 m³/h
  流速: 1.5 ~ 2.5 m/s
```

**热水 (HW - Hot Water)**
```yaml
用途: 空调采暖、生活热水
温度参数:
  空调热水: 45°C / 40°C (供/回)
  生活热水: 60°C / 50°C (供/回)
```

**冷却水 (CW - Condenser Water)**
```yaml
用途: 冷却制冷设备冷凝器
温度参数:
  供水: 32°C (从冷却塔)
  回水: 37°C (回冷却塔)
温差: 5K
```

### 空气流

**送风 (Supply Air)**
```yaml
处理过程: 过滤 → 冷却/加热 → 加湿 → 送风
温度参数:
  夏季: 14 ~ 16°C
  冬季: 28 ~ 32°C
风量指标:
  新风量: 按人员计算 (30 ~ 50 m³/h·人)
  总风量: 按换气次数计算
```

**回风 (Return Air)**
```yaml
处理方式:
  - 部分回风: 与新风混合后重新处理 (节能)
  - 全部回风: 循环使用
  - 无回风: 全新风 (有污染风险)
典型比例: 70% 回风 + 30% 新风
```

**排风 (Exhaust Air)**
```yaml
排风类型:
  - 一般排风: 卫生间、设备间
  - 工艺排风: 实验室、检验科
  - 污染排风: 感染病房、负压隔离区
```

**新风 (Fresh Air)**
```yaml
处理要求:
  - 过滤: G4 → F7 (初效 → 中效)
  - 预处理: 夏季预冷，冬季预热
新风量标准:
  - 一般诊室: 3 ACH (Air Changes per Hour)
  - 手术室: 15 ACH
  - 传染病房: 12 ACH (全新风)
```

### 医用气体流

**氧气 (OXY)**
```yaml
供应压力: 0.4 ~ 0.6 MPa
使用压力: 0.4 MPa
纯度: ≥ 99.5%
流量:
  单个终端: 10 ~ 100 L/min
  手术台: 40 ~ 100 L/min
```

**压缩空气 (AIR)**
```yaml
供应压力: 0.6 ~ 0.8 MPa
露点: ≤ -23°C
含油量: ≤ 0.1 mg/m³
```

**负压吸引 (VAC)**
```yaml
负压值: -0.04 ~ -0.09 MPa
流量: 30 ~ 80 L/min
过滤器: 必须设置细菌过滤器
```

## 能量流 (Energy Flow)

### 冷能流

**能量计算公式**
```
Q = m × c × ΔT

Q: 制冷量 (kW)
m: 质量流量 (kg/s)
c: 比热容 (kJ/kg·K)
ΔT: 温差 (K)

冷冻水: Q = m(kg/s) × 4.18(kJ/kgK) × (12-7)(K)
```

**示例：冷冻水空调系统**
```yaml
源: 冷水机组蒸发器
  制冷量: 1055 kW
  供水温度: 7°C
能量传递路径:
  - 冷冻水泵 (输入电能，提高压力)
  - 分水器 (分配流量)
  - AHU (吸收室内空气热量)
汇: 室内热量 (被移除)

能效比: COP 5.7 (制冷输出/电输入)
```

### 热能流

**示例：热水采暖**
```yaml
热源: 锅炉
  制热量: 2000 kW
  供水温度: 85°C
能量传递:
  - 热水泵 (输送)
  - 分水器 (分配)
  - FCU (向室内放热)
回水温度: 60°C
```

### 电能流

```
电源 → 变压器 → 低压配电柜 → 配电箱 → 设备
(10kV)   (380V)      (380V)        (220V)
```

**电能质量要求**
- 电压稳定: ±5%
- 频率稳定: 50Hz ±0.5%
- 谐波畸变: < 5%
- 备用电源: 10ms 切换

## 信息流 (Information Flow)

### 控制信号流

**信号类型**
- **模拟信号**: 4-20mA, 0-10V
- **数字信号**: 开关信号
- **网络信号**: BACnet, Modbus, LonWorks

**示例：空调机组控制**
```yaml
控制路径:
  传感器层:
    - T_Supply: AI-301 (供水温度, 4-20mA)
    - T_Return: AI-302 (回水温度, 4-20mA)
    - P_Supply: AI-303 (供水压力, 4-20mA)
  
  控制器层 (DDC):
    - 接收传感器信号
    - 执行 PID 计算
    - 输出控制命令
  
  执行器层:
    - Valve_CHW: AO-301 (冷水阀, 0-10V)
    - Pump_Enable: DO-301 (水泵启停)

控制策略:
  - 串级控制: 根据回风温度调节送风温度设定值
  - 根据送风温度调节冷热水阀开度
  - 根据末端需求调节水泵频率
```

### 传感器数据流

**数据特征**
- 采样频率: 1秒 ~ 10分钟
- 传输延迟: < 100ms (实时控制)

**示例**
```yaml
数据点:
  - CHW_Supply_Temp:
      point_name: "空调冷冻水供水温度"
      point_type: AI (模拟输入)
      unit: °C
      range: 0 ~ 20
      accuracy: ±0.5°C
      scan_rate: 10秒
```

### 告警信息流

**告警等级**
- **紧急 (Critical)**: 生命安全，立即响应
- **重要 (High)**: 设备停运，4小时响应
- **一般 (Medium)**: 性能下降，24小时响应
- **信息 (Low)**: 状态变化，记录即可

**告警流程**
```
告警触发 → 本地确认 → 上级通知 → 工单派发 → 处理 → 关闭
```

## 三流融合示例

以空调系统为例：

```yaml
时间: 上午 10:00
室外温度: 35°C
负荷: 人员 100人

物质流 (过程):
  ① 冷冻水流动: 冷水机 → 水泵 → AHU
     流量: 150 m³/h，温度: 7°C/12°C
  
  ② 空气流动: AHU → 风管 → 房间
     风量: 20000 m³/h，温度: 16°C

能量流 (过程):
  ① 电输入: 冷机耗电 185 kW + 水泵耗电 30 kW
  ② 制冷输出: 1055 kW
  ③ 能效比: COP 5.7

信息流 (过程):
  ① 传感器测量: T_supply, T_return, Flow
  ② 控制器计算: 实际制冷量 = 944 kW，负荷率 89%
  ③ 执行器动作: 冷水阀开度 85%
  ④ 数据记录: 存入历史数据库
```

## 流动模型的数学表达

### 物质流平衡方程

```
质量守恒: Σ(流入质量) = Σ(流出质量)

示例: 冷冻水平衡
  m_chw_supply = m_ahu_1 + m_ahu_2 + ... + m_ahu_n
```

### 能量平衡方程

```
能量守恒: Q_in + W_in = Q_out + W_out

示例: AHU 能量平衡
  Q_cooling = m_chw × c × ΔT
```

## 流动模型的应用

### 故障诊断

**场景**: 某房间温度偏高

**流动分析**:
```
Step 1: 检查空气流
  - 送风量是否足够?
  - 房间压差是否正常?

Step 2: 检查物质流
  - FCU 水阀开度是否足够?
  - 冷冻水温度是否正常?

Step 3: 检查能量流
  - FCU 制冷能力是否衰减?
  - 房间热负荷是否超过设计?

Step 4: 检查信息流
  - 传感器读数是否准确?
  - 控制指令是否正确送达?
```

### 能耗分析

**场景**: 手术室空调能耗异常高

**流动追踪**:
```
Input: 电能 → 冷机、水泵、风机
        ↓
Process: 电能 → 冷能 (COP = 5.7)
         ↓
         输配 (水泵效率 70%)
         ↓
         空气输送 (风机效率 65%)
         ↓
Output: 移除室内热量

优化机会:
  - 冷却水温度设定可否提高?
  - 水泵变频控制是否合理?
  - 新风量是否过量?
```

## 小结

三层流动的关系: **物质流是载体，能量流是内容，信息流是神经。**

流动模型实现了：
1. **系统思维**: 从设备到系统整体
2. **能量守恒**: 量化能量转换与损失
3. **故障溯源**: 追踪问题根源
4. **优化指导**: 识别节能潜力
