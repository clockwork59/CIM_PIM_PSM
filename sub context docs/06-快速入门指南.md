# 快速入门指南

> 本文档帮助新加入的开发人员快速了解项目并开始工作。

## 5分钟了解项目

### 这是什么项目？

医疗建筑CIM（统一领域模型）是一个**知识工程**项目，目标是为医疗建筑技术系统建立数字化模型，实现从设计到运营的数字化贯通。

### 核心交付物是什么？

不是传统软件代码，而是：
- **本体定义文件** (JSON-LD) - 定义医疗建筑领域的概念、属性、关系
- **文档体系** (Markdown) - 35+篇专业知识文档
- **CIM数据包** - 包含实体、关系、验证报告的标准化数据包

### 谁在参与？

9个专业Agent协作完成：
- Agent-01~08: 各专业建模师（系统、空间、设备、流动、控制、计量、运维）
- Agent-09: 模型整合验证师

## 常见问题

### Q1: 这个项目写代码吗？

**答**: 主要是知识工程工作，输出是文档和数据文件。代码主要是：
- `generate_cim_bundle.sh` - 数据包生成脚本
- `codex/` 中的HTML可视化

如果要做软件开发，通常是基于CIM模型开发应用（PSM层）。

### Q2: 如何理解CIM-PIM-PSM？

**答**: 用"做饭"类比：
- **CIM**: "我要做一道红烧肉，要肥而不腻"（业务需求）
- **PIM**: "需要五花肉500g，先焯水再炒糖色"（设计方案）
- **PSM**: "用苏泊尔炒锅，中火翻炒5分钟"（具体实现）

### Q3: Agent是什么？是AI吗？

**答**: Agent是**角色定义**，描述某类专业人员的工作职责。可以是：
- 真人的角色（如"张三作为Agent-01负责系统拓扑建模"）
- AI助手的角色（如"使用Claude作为Agent-09进行模型验证"）

### Q4: 如何快速贡献？

**答**: 根据你的背景选择切入点：

- **建筑/机电背景**: 参与Agent-01~03的建模工作
- **软件开发背景**: 基于CIM开发应用工具（PSM层）
- **数据分析背景**: 参与Agent-04流动模型或Agent-07计量体系
- **产品经理背景**: 参与文档体系完善和案例研究
