# 系统与空间耦合

> 本文档介绍机电系统与建筑空间的关联关系建模（Agent-05专业领域）。

## 概述

系统-空间耦合是连接"设备系统"与"建筑空间"的关键环节，回答以下核心问题：
- 设备在哪里？（设备定位）
- 系统服务哪些空间？（服务范围）
- 空间需要什么？（需求映射）

## 耦合关系类型

### 1. 设备-位置关系

设备位于哪个空间：

```yaml
设备定位示例:
  设备: CH-3F-01 (1号冷水机组)
  所在空间: BLDG01-L3-MECH (3层空调机房)
  定位信息:
    - 房间编号: 3F-MECH-01
    - 具体位置: 房间东北角
    - 基础标高: +0.3m

  设备: AHU-3F-01 (1号空调机组)
  所在空间: BLDG01-L3-AHU (3层空调机房)
  服务区域: BLDG01-L3-ZMED-OP (3层门诊医疗区)
```

### 2. 管路-穿越空间关系

管路经过哪些空间：

```yaml
管路路径示例:
  管路: CHW-MAIN-3F (3层冷冻水主管)
  起点: CH-3F-01 (冷水机组)
  终点: AHU-3F-01..05 (各空调机组)
  穿越空间:
    - BLDG01-L3-MECH (空调机房)
    - BLDG01-L3-CORR-01 (走廊)
    - BLDG01-L3-AHU (空调机房)
  安装信息:
    - 管径: DN200
    - 标高: +3.5m (吊顶内)
    - 保温: 橡塑保温，厚度 50mm
```

### 3. 系统-服务空间关系

系统服务哪些空间：

```yaml
系统服务示例:
  系统: HVAC-AHU-3F-001 (3层1号空调系统)
  服务区域:
    - Zone: BLDG01-L3-ZMED-OP (3层门诊医疗区)
    - 包含房间:
      - ROOM-301 (内科诊室-301)
      - ROOM-302 (内科诊室-302)
      - ROOM-303 (内科诊室-303)
      - ROOM-310 (候诊区)
    - 总服务面积: 800 m²
    - 总服务体积: 2560 m³
```

### 4. 空间环境要求映射

空间需求如何映射到系统设计：

```yaml
空间需求示例:
  空间: ROOM-301 (内科诊室-301)
  面积: 20 m²
  体积: 64 m³
  
  环境需求:
    - 温度: 24°C (夏季) / 22°C (冬季)
    - 湿度: 50% RH
    - 新风量: 100 m³/h
    - 噪声: ≤ 45 dB
  
  负荷计算:
    - 人员负荷: 4人 × 100W = 400W
    - 照明负荷: 100W
    - 设备负荷: 500W
    - 新风负荷: 2500W
    - 总冷负荷: 3496W
    - 单位面积负荷: 175 W/m²
  
  设备配置:
    - 末端: FCU-3F-08 (风机盘管，额定制冷量 4kW)
    - 送风: DIFF-SUP-301 (送风口)
    - 回风: GRILLE-RET-301 (回风口)
```

## 空间负荷计算

### 负荷组成

```yaml
空间冷负荷组成:
  - 围护结构负荷: 通过墙体、屋顶、窗户传入的热量
  - 人员负荷: 人员散热散湿
  - 照明负荷: 灯具散热
  - 设备负荷: 医疗设备、电脑等散热
  - 新风负荷: 处理新风所需的冷量
  - 渗透风负荷: 门窗缝隙渗入空气
```

### 负荷计算示例

```yaml
房间: 手术室-OR-301 (30m²)
计算参数:
  室外计算温度: 35°C (夏季)
  室内温度: 22°C
  人员: 8人 (医生4 + 护士4)

负荷计算:
  围护结构: 2000W
  人员: 8 × 100W = 800W
  照明: 30m² × 30W/m² = 900W
  设备: 2000W (无影灯 + 设备)
  新风: 1500 m³/h × 25W/m³h = 3750W
  
  总冷负荷: 9450W
  单位面积负荷: 315 W/m²
  换气次数: 20 ACH

设备选型:
  洁净空调机组: MAU-OR-01 + AHU-OR-01
  送风量: 15000 m³/h (其中新风 3000 m³/h)
  制冷量: 12 kW
  加湿量: 15 kg/h
```

## 能耗分摊规则

### 分摊方法

```yaml
能耗分摊方法:
  按面积分摊:
    适用: 公共区域照明、空调
    公式: 房间能耗 = 总能耗 × (房间面积 / 总面积)
  
  按人员分摊:
    适用: 新风系统
    公式: 房间能耗 = 总能耗 × (房间人数 / 总人数)
  
  按使用时间分摊:
    适用: 设备用电
    公式: 房间能耗 = 总能耗 × (房间使用时长 / 总时长)
  
  按负荷比例分摊:
    适用: 中央空调系统
    公式: 房间能耗 = 总能耗 × (房间负荷 / 总负荷)
```

### 分摊示例

```yaml
场景: 门诊综合楼3层空调总能耗 = 10000 kWh

分摊路径:
  1. 按面积分摊到区域:
     - 内科诊区 (800m²): 4000 kWh
     - 外科诊区 (600m²): 3000 kWh
     - 候诊大厅 (600m²): 3000 kWh

  2. 按负荷分摊到房间 (以内科诊区为例):
     - ROOM-301 (20m², 3.5kW): 400 kWh
     - ROOM-302 (20m², 3.5kW): 400 kWh
     - ROOM-310 (100m², 候诊区, 高负荷): 1500 kWh
```

## 耦合关系建模

### 关系类型定义

```yaml
耦合关系类型:
  LOCATED_IN: 设备位于空间
    示例: FCU-301 LOCATED_IN ROOM-301
  
  SERVES: 系统/设备服务空间
    示例: AHU-3F-001 SERVES ZONE-MEDICAL-OP
  
  ROUTES_THROUGH: 管路穿越空间
    示例: PIPE-CHW-001 ROUTES_THROUGH CORRIDOR-3F
  
  PROVIDES: 空间提供位置
    示例: ROOM-MECH PROVIDES_LOCATION CH-3F-01
```

### 耦合矩阵示例

```yaml
系统-空间耦合矩阵:
  系统: HVAC-AHU-3F-001
  服务空间:
    - ROOM-301: { area: 20m², load: 3.5kW, temp_setpoint: 24°C }
    - ROOM-302: { area: 20m², load: 3.5kW, temp_setpoint: 24°C }
    - ROOM-303: { area: 20m², load: 3.5kW, temp_setpoint: 24°C }
    - ROOM-310: { area: 100m², load: 15kW, temp_setpoint: 25°C }
  
  汇总:
    total_area: 800 m²
    total_load: 100 kW
    average_load_density: 125 W/m²
```

## 特殊空间耦合

### 手术室耦合

```yaml
空间: 手术室-OR-301
特殊性:
  - 洁净度: ISO Class 5
  - 压差: +10Pa (相对走廊)
  - 温度: 21~24°C (严格)
  - 湿度: 45~60% RH

系统耦合:
  - 洁净空调系统: HVAC-CLEAN-OR-001
  - 独立控制: 不接受楼宇统一调度
  - 应急电源: 必须接入EPS/UPS
  - 气体系统: 氧气、压缩空气、负压吸引
  - 监测系统: 温度、湿度、压差、粒子计数
```

### ICU耦合

```yaml
空间: ICU-ICU-301
特殊性:
  - 24小时运行
  - 不能停空调
  - 双路供电

系统耦合:
  - 空调系统: N+1配置 (一台故障，备用启动)
  - 电力系统: 双路供电 + UPS
  - 气体系统: 持续供氧
  - 监测系统: 生命支持设备监控
```
