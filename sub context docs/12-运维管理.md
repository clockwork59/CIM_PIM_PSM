# 运维管理

> 本文档介绍医疗建筑运维管理建模，包括告警管理、工单流程、维护策略（Agent-08专业领域）。

## 概述

医疗建筑运维管理确保机电系统安全、可靠、高效运行，保障医疗环境稳定。CIM运维管理建模涵盖：
- **告警管理**: 及时发现和处理异常
- **工单管理**: 规范化运维流程
- **维护管理**: 预防性维护和预测性维护
- **资产管理**: 设备全生命周期管理

## 告警管理

### 告警级别

```yaml
告警级别定义:
  
  CRITICAL (紧急):
    定义: 影响生命安全或核心医疗功能
    响应时间: 立即 (5分钟内)
    通知方式: 电话 + 短信 + APP推送 + 声光报警
    示例:
      - 手术室空调故障
      - ICU供电中断
      - 消防系统故障
      - 医疗气体压力异常
  
  HIGH (重要):
    定义: 影响系统运行或医疗环境
    响应时间: 15分钟内
    通知方式: 短信 + APP推送 + 监控弹窗
    示例:
      - 冷水机组故障
      - 重要区域温湿度超标
      - 电梯故障
      - 主要设备离线
  
  MEDIUM (一般):
    定义: 性能下降或潜在风险
    响应时间: 1小时内
    通知方式: APP推送 + 监控提示
    示例:
      - 过滤网堵塞
      - 备用设备启动
      - 能耗异常升高
  
  LOW (信息):
    定义: 状态变化或提示信息
    响应时间: 记录即可
    通知方式: 仅记录
    示例:
      - 设备启停
      - 模式切换
      - 定期自检完成
```

### 告警类型

```yaml
告警类型:
  
  超限告警:
    触发: 参数超出设定范围
    示例:
      - 温度超高/超低
      - 压力超高/超低
      - 流量异常
      - 湿度过高/过低
  
  离线告警:
    触发: 设备通信中断
    示例:
      - DDC离线
      - 传感器离线
      - 智能电表离线
  
  故障告警:
    触发: 设备故障状态
    示例:
      - 冷机故障
      - 风机故障
      - 变频器故障
  
  状态告警:
    触发: 设备状态异常
    示例:
      - 备用设备启动
      - 手动模式运行
      - 维护模式
```

### 告警流程

```
告警触发
    ↓
告警抑制检查 (是否应抑制)
    ↓
告警确认 (自动/人工)
    ↓
通知发送 (根据级别)
    ↓
工单创建 (自动/人工)
    ↓
处理执行
    ↓
处理确认
    ↓
告警关闭
```

### 告警示例

```yaml
告警实例:
  告警ID: ALM-2025-12-18-001
  告警时间: 2025-12-18 10:23:45
  告警级别: HIGH
  告警类型: 故障告警
  
  告警对象:
    设备: CH-3F-01 (1号冷水机组)
    系统: HVAC-CHP-001 (冷冻水系统)
```

## 工单管理

### 工单类型

```yaml
工单类型:
  
  维修工单 (CM - Corrective Maintenance):
    定义: 故障发生后的修复性维修
    触发: 告警、报修
    时效: 根据告警级别
  
  保养工单 (PM - Preventive Maintenance):
    定义: 按计划进行的预防性保养
    触发: 时间周期
    周期: 日检、周检、月检、季检、年检
  
  巡检工单 (Inspection):
    定义: 定期巡检检查
    触发: 计划安排
    内容: 设备状态检查、参数记录
  
  改造工单 (Upgrade):
    定义: 设备改造升级
    触发: 计划申请
    流程: 申请 → 审批 → 实施 → 验收
```

### 工单状态

```yaml
工单状态流转:
  
  待处理 (Pending):
    工单已创建，等待派工
  
  已派工 (Assigned):
    已分配给工程师
  
  处理中 (In Progress):
    工程师正在处理
  
  待确认 (Pending Confirm):
    处理完成，等待确认
  
  已完成 (Completed):
    工单完成
  
  已关闭 (Closed):
    工单关闭，归档
```

### 工单示例

```yaml
工单实例:
  工单编号: WO-2025-12-18-045
  工单类型: PM (预防性保养)
  工单状态: 已完成
  
  设备信息:
    设备: CH-3F-01 (1号冷水机组)
    位置: 3层空调机房
  
  计划信息:
```

## 维护策略

### 维护类型

```yaml
维护类型:
  
  日常巡检 (Daily Inspection):
    频率: 每日
    内容:
      - 设备运行状态检查
      - 温湿度参数查看
      - 告警信息确认
    人员: 值班工程师
  
  定期保养 (Preventive Maintenance):
    频率: 按周期
    周期定义:
      - 周检: 每周一次
      - 月检: 每月一次
      - 季检: 每季度一次
      - 年检: 每年一次
    内容: 按SOP执行
  
  预测性维护 (Predictive Maintenance):
    定义: 基于状态监测的维护
    方法:
      - 振动分析
      - 温度趋势分析
      - 电流分析
      - 油液分析
    优势: 减少非计划停机
  
  修复性维护 (Corrective Maintenance):
    定义: 故障后的修复
    触发: 故障发生
    目标: 快速恢复运行
```

### 维护计划示例

```yaml
冷水机组维护计划:
  设备: CH-3F-01 (1号冷水机组)
  
  维护周期:
    日检:
      - 检查运行状态
      - 记录运行参数
      - 检查有无异常声音
    
    周检:
      - 清洁设备表面
      - 检查接线端子
      - 检查管道连接
    
    月检:
      - 检查冷冻油油位
      - 检查制冷剂压力
      - 清洁控制柜
    
    季检:
      - 更换油过滤器
      - 检查冷凝器清洁度
      - 检查蒸发器
      - 测试保护装置
    
    年检:
      - 全面性能测试
      - 绝缘检测
      - 全面清洁保养
      - 备件更换
```

## 资产管理

### 设备台账

```yaml
设备台账信息:
  基础信息:
    - 设备编号、名称、型号
    - 制造商、供应商
    - 安装位置、安装日期
    - 保修期、使用寿命
  
  技术参数:
    - 额定功率、容量
    - 运行参数范围
    - 技术规格书
  
  维护记录:
    - 保养历史
    - 维修历史
    - 故障历史
  
  成本信息:
    - 采购成本
    - 维护成本
    - 能耗成本
```

### 资产生命周期

```
规划 → 采购 → 安装 → 调试 → 运行 → 维护 → 改造 → 报废
  ↓                                                  ↓
需求分析                                        残值回收
供应商选择                                      数据归档
招标采购                                        环保处理
```

## 关键绩效指标 (KPI)

```yaml
运维KPI:
  
  可靠性指标:
    - MTBF (平均故障间隔时间)
    - MTTR (平均修复时间)
    - 设备完好率
  
  效率指标:
    - 工单完成率
    - 工单及时率
    - 首次修复率
  
  成本指标:
    - 维护成本占比
    - 能耗成本
    - 备件库存周转
  
  安全指标:
    - 安全事故次数
    - 安全隐患整改率
    - 培训完成率
```
