## 核心概念脑图

```
医疗建筑CIM项目
├── 愿景：让每座医疗建筑拥有"数字基因"
├── 架构：CIM → PIM → PSM
├── 系统：HVAC / 给排水 / 电气 / 智能化 / 医疗气体
├── 空间：Site → Building → Floor → Zone → Room → SubSpace
├── 设备：分类体系 + 属性模型
├── 流动：物质流 / 能量流 / 信息流
├── 耦合：系统-空间关联关系
├── 控制：传感器 → 控制器 → 执行器
├── 计量：层级计量 + 能耗分摊
├── 运维：告警 + 工单 + 维护
└── 团队：9个Agent协作
    ├── Agent-01~08: 各专业建模师
    └── Agent-09: 整合验证师
```
