# 控制系统

> 本文档介绍医疗建筑控制系统建模，包括传感器、执行器、控制回路和控制策略（Agent-06专业领域）。

## 概述

医疗建筑控制系统是维持环境参数稳定、保障医疗安全的核心。CIM控制系统建模需要定义：
- **感知层**: 各类传感器
- **执行层**: 阀门、风门、变频器等执行器
- **控制层**: DDC、PLC等控制器
- **策略层**: PID、串级、时间表等控制策略

## 控制系统架构

```
┌─────────────────────────────────────────┐
│  管理层 (BMS/EMS)                        │
│  监控、报警、优化                         │
├─────────────────────────────────────────┤
│  控制层 (DDC/PLC)                        │
│  逻辑运算、PID计算                        │
├─────────────────────────────────────────┤
│  现场层                                  │
│  传感器 ←──→ 执行器                       │
└─────────────────────────────────────────┘
```

## 传感器 (Sensors)

### 温度传感器

```yaml
温度传感器:
  类型:
    - PT100: 铂电阻，精度高，用于精密测量
    - NTC: 热敏电阻，成本低，用于一般测量
    - 热电偶: 量程宽，用于高温测量
  
  应用位置:
    - 冷冻水供回水温度
    - 空调机组送风温度
    - 房间室内温度
    - 室外温度
  
  技术参数:
    测量范围: -20°C ~ 100°C
    精度: ±0.5°C
    输出信号: 4-20mA / 0-10V / RS485
    响应时间: < 30秒
```

### 湿度传感器

```yaml
湿度传感器:
  类型: 电容式、电阻式
  
  应用位置:
    - 空调机组送风湿度
    - 房间室内湿度
    - 室外湿度
  
  技术参数:
    测量范围: 0% ~ 100% RH
    精度: ±3% RH
    输出信号: 4-20mA / 0-10V
```

### 压力传感器

```yaml
压力传感器:
  类型:
    - 压差传感器: 测量两点间压差
    - 绝压传感器: 测量绝对压力
    - 表压传感器: 测量相对压力
  
  应用位置:
    - 冷冻水供回水压差
    - 空气过滤器压差
    - 房间压差 (洁净室)
    - 风管静压
  
  技术参数:
    水系统: 0 ~ 1.0 MPa
    风系统: 0 ~ 500 Pa
    精度: ±1% FS
```

### 流量传感器

```yaml
流量传感器:
  类型:
    - 电磁流量计: 精度高，用于水系统
    - 超声波流量计: 非接触，安装方便
    - 涡街流量计: 用于蒸汽
    - 热式质量流量计: 用于气体
  
  应用位置:
    - 冷冻水流量
    - 冷却水流量
    - 送风风量
  
  技术参数:
    水系统精度: ±0.5% FS
    量程比: 10:1
```

### 其他传感器

```yaml
CO2传感器:
  用途: 监测室内空气质量，控制新风量
  测量范围: 0 ~ 2000 ppm
  精度: ±50 ppm

颗粒物传感器:
  用途: 监测PM2.5/PM10
  测量范围: 0 ~ 500 μg/m³

电力传感器:
  用途: 监测电压、电流、功率、电能
  类型: 智能电表、电流互感器
```

## 执行器 (Actuators)

### 阀门执行器

```yaml
电动调节阀:
  用途: 调节水流量
  类型:
    - 两通阀: 开关或调节
    - 三通阀: 混合或分流
  
  控制信号: 0-10V 或 4-20mA
  反馈信号: 阀位反馈 0-100%
  
  关键参数:
    - 口径: DN25 ~ DN300
    - 流量特性: 等百分比、线性
    - 关闭压差: 最大工作压力

电磁阀:
  用途: 快速开关控制
  类型: 常开型、常闭型
  控制信号: 数字信号 (ON/OFF)
```

### 风门执行器

```yaml
电动风门执行器:
  用途: 调节风量
  类型:
    - 开关型: 全开/全关
    - 调节型: 0-100% 开度调节
  
  控制信号: 0-10V / 4-20mA
  运行时间: 60秒 ~ 150秒 (全开)
  扭矩: 5Nm ~ 40Nm

应用:
  - 新风阀: 调节新风量
  - 回风阀: 调节回风比例
  - 排风阀: 调节排风量
  - 变风量末端: VAV Box
```

### 变频器 (VFD)

```yaml
变频器:
  用途: 调节电机转速，节能控制
  适用设备: 水泵、风机、压缩机
  
  控制方式:
    - 手动设定频率
    - 自动调节 (根据压力/流量/温度)
  
  技术参数:
    输入电压: 三相 380V
    功率范围: 0.75kW ~ 400kW
    调速范围: 0 ~ 50Hz
    控制精度: ±0.5Hz
  
  节能原理:
    风机功率 ∝ 转速³
    水泵功率 ∝ 转速³
    降低转速可大幅减少能耗
```

## 控制器 (Controllers)

### DDC控制器

```yaml
DDC (Direct Digital Controller):
  功能: 直接数字控制，楼宇自控的核心
  
  硬件接口:
    模拟输入 (AI): 4-20mA, 0-10V (传感器)
    模拟输出 (AO): 4-20mA, 0-10V (调节阀)
    数字输入 (DI): 干接点 (状态、报警)
    数字输出 (DO): 继电器 (启停控制)
  
  通信接口:
    - BACnet: 标准楼宇自控协议
    - Modbus: 工业常用协议
    - LonWorks: 现场总线
  
  编程:
    图形化编程或脚本语言
    支持PID算法、逻辑运算、时间表
```

### PLC控制器

```yaml
PLC (Programmable Logic Controller):
  用途: 复杂逻辑控制、快速响应
  应用场景: 冷机群控、锅炉控制、发电机控制
  
  特点:
    - 响应速度快 (毫秒级)
    - 可靠性高
    - 扩展性强
  
  编程语言:
    - 梯形图 (Ladder)
    - 功能块图 (FBD)
    - 结构化文本 (ST)
```

## 控制回路

### 单回路PID控制

```yaml
PID控制:
  组成:
    P (比例): 根据偏差大小输出
    I (积分): 消除稳态误差
    D (微分): 预测变化趋势
  
  应用场景:
    - 房间温度控制
    - 冷冻水供水温度控制
    - 风管静压控制
  
  参数整定:
    Kp (比例系数): 响应速度
    Ki (积分时间): 消除静差
    Kd (微分时间): 抑制超调

示例: 房间温度PID控制
  设定值: 24°C
  测量值: 26°C
  偏差: 2°C
  
  PID计算:
    P = Kp × 偏差 = 2 × 2 = 4
    I = Ki × ∫偏差 = 0.5 × 2 = 1
    D = Kd × d偏差/dt = 0.1 × 0 = 0
    输出: 55% (冷水阀开度)
```

### 串级控制

```yaml
串级控制 (Cascade Control):
  特点: 两个PID回路嵌套
  
  主回路 (外环):
    - 被控量: 房间温度
    - 输出: 送风温度设定值
  
  副回路 (内环):
    - 被控量: 送风温度
    - 输出: 冷水阀开度
  
  优势:
    - 响应更快
    - 抗干扰能力强
  
  应用场景:
    - 空调机组控制
    - 洁净室控制
```

### 分程控制

```yaml
分程控制 (Split Range Control):
  特点: 一个控制器输出控制两个执行器
  
  示例: 空调机组温度控制
    输出 0-50%: 控制冷水阀 (降温)
    输出 50-100%: 控制热水阀 (加热)
```

## 控制策略

### 时间表控制

```yaml
时间表控制 (Schedule Control):
  用途: 按时间启停设备
  
  示例: 空调系统时间表
    工作日:
      - 07:00: 预冷启动 (提前降温)
      - 08:00: 正常运营
      - 18:00: 降负荷运行
      - 22:00: 停机 (仅保持通风)
    
    周末:
      - 08:00: 轻度运行
      - 18:00: 停机
```

### 需求控制

```yaml
需求控制 (Demand Control):
  用途: 根据实际需求调节
  
  示例: 新风量需求控制
    - CO2浓度 < 800ppm: 最小新风量
    - CO2浓度 800-1000ppm: 增加新风量
    - CO2浓度 > 1000ppm: 最大新风量
```

### 优化控制

```yaml
优化控制:
  冷机群控优化:
    - 根据负荷决定开启台数
    - 均衡各台运行时间
    - 选择效率最高的组合
  
  冷却水优化:
    - 根据湿球温度调节冷却塔
    - 降低冷却水温度提高冷机效率
  
  输配系统优化:
    - 变流量运行
    - 最不利末端压差控制
```

## 控制示例：空调机组

```yaml
系统: AHU-3F-001 (空调机组)

控制点配置:
  模拟输入 (AI):
    - AI-01: 送风温度
    - AI-02: 回风温度
    - AI-03: 冷冻水供水温度
    - AI-04: 冷冻水回水温度
    - AI-05: 过滤器压差
  
  模拟输出 (AO):
    - AO-01: 冷水阀开度 (0-100%)
    - AO-02: 热水阀开度 (0-100%)
    - AO-03: 加湿器输出 (0-100%)
  
  数字输入 (DI):
    - DI-01: 风机运行状态
    - DI-02: 风机故障报警
    - DI-03: 过滤器堵塞报警
    - DI-04: 防冻开关
  
  数字输出 (DO):
    - DO-01: 风机启停控制
    - DO-02: 新风机启停

控制逻辑:
  送风温度控制:
    - 夏季: 根据送风温度PID调节冷水阀
    - 冬季: 根据送风温度PID调节热水阀
    - 过渡季: 使用经济器模式 (全新风)
  
  房间温度控制 (串级):
    - 主回路: 根据房间温度调节送风温度设定值
    - 副回路: 根据送风温度调节阀门
  
  湿度控制:
    - 夏季: 冷却除湿
    - 冬季: 蒸汽加湿
  
  联锁保护:
    - 风机停止时，关闭所有阀门
    - 过滤器堵塞报警
    - 防冻保护 (冬季)
```

## 快速参考

| 控制类型 | 适用场景 | 特点 |
|---------|----------|------|
| ON/OFF | 简单启停 | 简单，但波动大 |
| PID | 温度/压力/流量 | 精确，稳态无差 |
| 串级 | 空调机组 | 响应快，抗干扰 |
| 分程 | 加热/制冷切换 | 平滑过渡 |
| 时间表 | 设备启停 | 节能 |
| 需求 | 新风控制 | 按需供给 |
