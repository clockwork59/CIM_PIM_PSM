# 设备本体建模

> 本文档介绍医疗建筑设备分类体系与属性建模（Agent-03专业领域）。

## 概述

设备本体建模是CIM建模的核心环节，目标是建立医疗建筑中所有机电设备的数字化"身份证"——包括设备类型、属性、组件结构和控制规则。

## 设备分类体系

### HVAC设备

```yaml
冷源设备:
  - 冷水机组 (Chiller)
    - 类型: 离心式、螺杆式、涡旋式、吸收式
    - 关键属性: 制冷量(kW)、COP、冷冻水温度、冷却水温度
  
  - 冷却塔 (Cooling Tower)
    - 类型: 横流式、逆流式、闭式
    - 关键属性: 冷却能力、风量、水流量、噪音

输配设备:
  - 冷冻水泵 (Chilled Water Pump)
    - 类型: 离心泵、变频泵
    - 关键属性: 流量(m³/h)、扬程(m)、功率(kW)、效率
  
  - 冷却水泵 (Condenser Water Pump)
  
  - 热水泵 (Hot Water Pump)

空气处理设备:
  - 空调机组 (AHU - Air Handling Unit)
    - 类型: 组合式、柜式、吊装式
    - 关键属性: 风量(m³/h)、冷量(kW)、热量(kW)、机外静压(Pa)
    - 组件: 风机、盘管、过滤器、加湿器、消声器
  
  - 新风机组 (MAU - Make-up Air Unit)
  
  - 风机盘管 (FCU - Fan Coil Unit)
    - 类型: 卧式暗装、立式明装、卡式
    - 关键属性: 风量、冷量、热量、噪音
  
  - 变风量末端 (VAV Box)
    - 关键属性: 最大风量、最小风量、控制方式
```

### 电气设备

```yaml
变压设备:
  - 变压器 (Transformer)
    - 类型: 干式、油浸式
    - 关键属性: 容量(kVA)、电压等级、阻抗、效率

配电设备:
  - 高压开关柜 (HV Switchgear)
  - 低压开关柜 (LV Switchgear)
  - 配电箱 (Distribution Board)
    - 关键属性: 回路数、容量、保护等级

应急电源:
  - 柴油发电机 (Diesel Generator)
    - 关键属性: 额定功率(kW)、启动时间、燃油容量
  
  - UPS (Uninterruptible Power Supply)
    - 关键属性: 容量(kVA)、切换时间、后备时间
  
  - ATS (Automatic Transfer Switch)
    - 关键属性: 切换时间
```

### 给排水设备

```yaml
供水设备:
  - 生活水泵 (Domestic Water Pump)
  - 变频供水设备 (VFD Water Supply)
  - 水箱 (Water Tank)
    - 关键属性: 容积(m³)、材质、液位控制

热水设备:
  - 热水器 (Water Heater)
    - 类型: 电热水器、燃气热水器、太阳能
  - 热交换器 (Heat Exchanger)

排水设备:
  - 污水提升泵 (Sewage Lift Pump)
  - 隔油池 (Grease Trap)
```

### 医疗气体设备

```yaml
氧气系统:
  - 氧气汇流排 (Oxygen Manifold)
  - 液氧储罐 (Liquid Oxygen Tank)
  - 区域阀门箱 (Zone Valve Box)

压缩空气系统:
  - 空压机 (Air Compressor)
  - 储气罐 (Air Receiver)
  - 干燥机 (Dryer)

负压吸引系统:
  - 负压泵 (Vacuum Pump)
  - 真空罐 (Vacuum Tank)
```


## 编码规范

### 设备ID格式

```
{TYPE}-{LOCATION}-{NUMBER}

TYPE: 设备类型编码
  - CH: Chiller (冷水机组)
  - CT: Cooling Tower (冷却塔)
  - CHWP: Chilled Water Pump (冷冻水泵)
  - AHU: Air Handling Unit (空调机组)
  - FCU: Fan Coil Unit (风机盘管)
  - VAV: Variable Air Volume (变风量末端)
  - TR: Transformer (变压器)
  - GEN: Generator (发电机)
  - WP: Water Pump (水泵)

LOCATION: 位置编码
  - 3F: 3楼
  - B1: 地下1层
  - ROOF: 屋顶

NUMBER: 2位数字序号
  - 01, 02, 03...

示例:
  - CH-3F-01: 3楼1号冷机
  - AHU-B1-02: 地下1层2号空调机组
  - FCU-3F-15: 3楼15号风机盘管
```
