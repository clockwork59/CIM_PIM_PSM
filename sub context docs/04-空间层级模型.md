# 空间层级模型

> 本文档介绍医疗建筑空间的六层结构，是理解设备定位和系统服务范围的基础。

## 六层空间模型

```
Level_0_Site (站点) → Level_1_Building (建筑) → Level_2_Floor (楼层)
    → Level_3_Zone (区域) → Level_4_Room (房间) → Level_5_SubSpace (子空间)
```

## L0: Site (站点)

**定义**: 医疗建筑的完整地块，可能包含多栋建筑。

**属性**:
```yaml
site_id: "SITE-001"
site_name: "XX医院主院区"
address: "XX市XX区XX路XX号"
total_area_m2: 150000  # 总占地面积
built_area_m2: 85000   # 建筑面积
location:
  latitude: 39.9042
  longitude: 116.4074
climate_zone: "COLD"  # ASHRAE气候分区
```

**典型实例**:
- "北京协和医院主院区"
- "上海仁济医院东院区"

## L1: Building (建筑)

**定义**: 独立的功能建筑，每栋建筑有独立的建筑参数和用能特点。

**属性**:
```yaml
building_id: "BLDG-01"
building_name: "门诊综合楼"
building_type: "OUTPATIENT"  # OUTPATIENT/INPATIENT/MEDICAL_TECH
construction_year: 2020
floors_above_ground: 12
floors_below_ground: 3
total_floor_area_m2: 45000
building_envelope:
  wall_u_value: 0.35  # W/m²K
  window_u_value: 1.8  # W/m²K
  roof_u_value: 0.25  # W/m²K
```

**建筑类型枚举**:
- OUTPATIENT: 门诊楼
- INPATIENT: 住院楼
- MEDICAL_TECH: 医技楼
- ADMIN: 行政楼
- RESEARCH: 科研楼
- SUPPORT: 后勤楼
- INFECTIOUS: 感染楼（独立）

## L2: Floor (楼层)

**定义**: 建筑的横向分层，每层的用能特点和负荷特性可能不同。

**属性**:
```yaml
floor_id: "BLDG-01-L3"
floor_name: "3层"
floor_level: 3  # 楼层编号，地上为正，地下为负
total_area_m2: 3200
net_area_m2: 2880
ceiling_height_m: 3.2
floor_to_floor_height_m: 3.8
```

**楼层类型**:
- 地下楼层: B1, B2, B3...
- 地上楼层: L1, L2, L3...
- 特殊楼层: G (Ground), M (Mezzanine), R (Roof)

**用能特点**:
- B1-B3: 设备用房多，人员少，恒定负荷
- L1-L3: 门诊大厅，人流量大，人员负荷波动大
- L4-L10: 病房，人员稳定，24小时运行
- L11-L12: 办公，白天运行，夜间负荷低
- Roof: 设备机房，高能耗密度

## L3: Zone (区域)

**定义**: 功能相近的一组房间，是机电系统设计和能耗分析的重要层级。

**属性**:
```yaml
zone_id: "BLDG-01-L3-ZMED-OP"
zone_name: "3层门诊医疗区"
zone_type: "MEDICAL_OUTPATIENT"
area_m2: 800
occupancy_density_pax_m2: 0.2  # 人员密度
```

**区域类型枚举**:

**医疗区域**:
- MEDICAL_OUTPATIENT: 门诊医疗区
- MEDICAL_INPATIENT: 住院医疗区
- OPERATING: 手术区
- ICU: 重症监护区
- EMERGENCY: 急诊区
- RADIOLOGY: 放射科
- LABORATORY: 检验科
- PHARMACY: 药房

**辅助区域**:
- CIRCULATION: 交通核（电梯厅、走廊）
- SUPPORT: 辅助用房（污物间、配餐间）
- ADMIN: 办公区
- PUBLIC: 公共区（大厅、候诊）

**区域与系统关系**:
```yaml
区域: "3层门诊内科诊区"
被服务系统:
  - HVAC: "HVAC-AHU-3F-01"
  - 照明: "ELE-LIGHT-3F-01"
  - 插座: "ELE-POWER-3F-01"
```

## L4: Room (房间)

**定义**: 基本功能单元，是能耗计量、环境控制的最小单元。

**属性**:
```yaml
room_id: "BLDG-01-L3-ROOM-301"
room_name: "内科诊室-301"
room_type: "CONSULTING_ROOM"
area_m2: 20
volume_m3: 64  # 20m² × 3.2m
capacity_pax: 4
```

**房间类型枚举**:

**医疗房间**:
- CONSULTING_ROOM: 诊室
- EXAM_ROOM: 检查室
- TREATMENT_ROOM: 治疗室
- OPERATING_ROOM: 手术室 (ISO Class 5-7)
- ICU_BED: ICU 病床
- PATIENT_ROOM: 病房
- ISOLATION_ROOM: 隔离病房

**辅助房间**:
- TOILET: 卫生间
- STORAGE: 储藏室
- CLEANING_ROOM: 污物间
- NURSE_STATION: 护士站
- MEDICATION_ROOM: 配药室
- DOCTOR_OFFICE: 医生办公室

**特殊房间**:
- MRI_ROOM: MRI 机房 (特殊屏蔽要求)
- CT_ROOM: CT 机房
- XRAY_ROOM: X光机房
- LINAC_ROOM: 直线加速器机房

**房间与机电设备关系**:
```yaml
房间: "内科诊室-301"
空间负荷:
  - 人员: 4人 (4 × 100W = 400W)
  - 照明: 100W
  - 设备: 500W (电脑、医疗设备)
  - 总计: 1000W

末端设备:
  - FCU-3F-08: "风机盘管，提供冷热"
  - DIFF-SUP-301: "送风口"
  - GRILLE-RET-301: "回风口"
  - LIGHT-301-01..02: "照明灯具"

环境参数设定:
  - 温度设定: 24°C (夏季) / 22°C (冬季)
  - 湿度设定: 50% RH
  - 新风量: 100m³/h
```

## L5: SubSpace (子空间)

**定义**: 房间内的局部空间，用于更精细的设备定位或局部负荷计算。

**应用场景**:
1. **大型房间的局部区域** - 大厅的等候区、挂号区、取药区
2. **设备周围的局部空间** - MRI 设备周围的 5m x 5m 区域（散热集中）
3. **人员密度不同区域** - 诊室内的医生办公区、患者就诊区

**属性**:
```yaml
subspace_id: "BLDG-01-L3-ROOM-301-SS01"
subspace_name: "诊室工作区"
subspace_type: "WORKING_AREA"
area_m2: 6
location_in_room: "靠近窗户侧"
```

## 层级关系

### 包含关系 (Containment)

```
Site --(contains)--> Building  (1:N)
Building --(contains)--> Floor  (1:N)
Floor --(contains)--> Zone  (1:N)
Zone --(contains)--> Room  (1:N)
Room --(contains)--> SubSpace  (1:N)
```

### 服务关系 (Service)

```
System --(serves: 1:N)--> Zone
System --(serves: 1:N)--> Room
Equipment --(serves: 1:N)--> Room
Equipment --(located_in: N:1)--> Room
```

**示例**: AHU-3F-01 服务 "3层门诊医疗区"
```yaml
设备: AHU-3F-01
服务区域: BLDG-01-L3-ZMED-OP (3层门诊医疗区, Zone层级)
包含末端:
  - ROOM-301 (内科诊室-301)
  - ROOM-302 (内科诊室-302)
  - ROOM-303 (内科诊室-303)
  - 等等...
```

## 空间属性继承

子层级自动继承父层级的部分属性，但可以覆盖：

```
Site
├── climate_zone: "COLD"
└── Building-01
    ├── construction_year: 2020
    ├── building_envelope: {...}
    └── Floor-3
        ├── ceiling_height_m: 3.2
        └── Zone-MEDICAL
            ├── occupancy_density: 0.2 pax/m²
            └── Room-301 (内科诊室)
                ├── area_m2: 20 (继承:occupancy_density → 4人)
                └── temperature_setpoint: 24°C (覆盖默认值)
```

## 空间编码规则

### 完整编码格式

```
{Site}-{Building}-{Floor}-{Zone}-{Room}-{SubSpace}

示例: SITE-001-BLDG01-L3-ZMED-OP-ROOM301-SS01

简化: BLDG01-L3-ROOM301
或: OR-3F-01 (手术室编号)
```

### 编码约定

1. **唯一性**: 在整个项目中唯一
2. **可读性**: 从编码可看出层级关系
3. **稳定性**: 建筑改造时尽量不更改 ID
4. **兼容性**: 兼容 BIM 的 IfcSpace GlobalId

## 空间与能耗分摊

### 空间层级与能耗计量层级对应

```
L0 Site
├── 总能耗 (总电表、总水表)
↓
L1 Building
├── 建筑总能耗 (建筑总表)
↓
L2 Floor
├── 楼层能耗 (楼层分表)
↓
L3 Zone
├── 区域能耗 (区域计量)
↓
L4 Room
├── 房间能耗 (房间子表)
↓
L5 SubSpace / Equipment
└── 设备能耗 (设备计量)
```

### 能耗分摊示例

```yaml
场景: "门诊综合楼3层总能耗 = 10000 kWh"

分摊路径:
  1. 按面积分摊到区域:
     - 内科诊区 (800m²): 4000 kWh
     - 外科诊区 (600m²): 3000 kWh
     - 候诊大厅 (600m²): 3000 kWh

  2. 按人员密度分摊到房间 (以内科诊区为例):
     - ROOM-301 (4人): 500 kWh
     - ROOM-302 (4人): 500 kWh
     - ROOM-303 (4人): 500 kWh

  3. 设备级计量 (可选):
     - FCU-3F-08: 100 kWh
     - LIGHT-301: 50 kWh
     - EQUP-301: 150 kWh
```

## 空间模型应用场景

### 场景 1: 系统服务范围定义

```yaml
系统: HVAC-AHU-3F-01
覆盖空间:
  Zone: ["BLDG01-L3-ZMED-OP", "BLDG01-L3-ZMED-ICU"]
  Room: ["ROOM-301".."ROOM-330"]
  总服务面积: 2400 m²
```

### 场景 2: 负荷计算

```yaml
空间: ROOM-301 (内科诊室, 20m²)
负荷类型:
  - 人员负荷: 4人 × 100W = 400W
  - 照明负荷: 8m² × 12W/m² = 96W
  - 设备负荷: 500W (医疗设备、电脑)
  - 新风负荷: 100m³/h × 25W/m³h = 2500W

总冷负荷: 3496W
单位面积负荷: 175 W/m²
```

### 场景 3: BIM 映射

```
CIM Space              ←→  BIM IfcSpace
BLDG01-L3-ROOM301           IfcSpace.GlobalId: "2QRJSY$9L6oB7KJw4"
area_m2: 20                 IfcSpace.GrossFloorArea: 20m²
volume_m3: 64               IfcSpace.Volume: 64m³
```
