# 医疗建筑CIM领域概述

> 本文档面向不熟悉医疗建筑领域的开发人员，提供核心领域知识快速入门。

## 什么是CIM？

**CIM（Common Information Model，统一领域模型）** 是医疗建筑技术系统的"数字基因"——从设计蓝图到运营优化的完整数字孪生体。

不是简单的BIM模型，而是：
- 能够理解机电系统运行逻辑的"数字大脑"
- 能够预测能耗与故障的"数字先知"
- 能够自主优化控制策略的"数字管家"

## 项目愿景

让每一座医疗建筑都拥有可计算、可推理、可优化的"数字基因"。

### 三大战略目标

| 目标 | 现状 | 愿景 |
|------|------|------|
| **信息整合** | 20-50个独立系统，数据无法互通 | 单一CIM模型驱动所有子系统，语义互操作100% |
| **预测能力** | 故障发生后才报警 | 提前7天预测设备故障，准确率85% |
| **知识传承** | 专家经验无法传承 | 建立医疗建筑CIM知识库，全行业共享 |

## 核心技术原则

1. **本体优先（Ontology-First）**: 系统理解"概念"，而不仅是"几何"
2. **时空原生（Spatiotemporal-Native）**: 4D事件建模（3D空间 + 1D时间）
3. **流动中心（Flow-Centric）**: 关注物质、能量、信息的三流合一
4. **知识驱动（Knowledge-Driven）**: 可学习、可进化的知识系统
5. **开放生态（Open Ecosystem）**: 与BIM/IFC/openBIM无缝整合

## CIM-PIM-PSM三层架构

```
┌─────────────────────────────────────────────────┐
│         CIM (计算无关模型)                        │
│  领域概念、业务规则、自然语言描述                  │
│  "WHAT" - 做什么                                │
├─────────────────────────────────────────────────┤
│         PIM (平台无关模型)                        │
│  逻辑结构、API契约、技术中立设计                   │
│  "HOW TO DESIGN" - 如何设计                      │
├─────────────────────────────────────────────────┤
│         PSM (平台特定模型)                        │
│  具体实现、代码生成、平台相关部署                  │
│  "HOW TO CODE" - 如何编码                        │
└─────────────────────────────────────────────────┘
```

### 层次说明

- **CIM层**: 业务专家眼中的世界，使用自然语言描述"手术室温度必须保持在21-24°C"
- **PIM层**: 架构师的设计，定义接口和逻辑结构，如`ControlLoop`接口定义
- **PSM层**: 开发者的实现，具体代码如`OperatingRoomController`类

## 五大建筑系统

医疗建筑包含五大主系统：

```
医疗建筑系统
├── HVAC (暖通空调系统) - 冷热源、空气处理、洁净空调
├── PLUMBING (给排水系统) - 生活给水、热水、排水、纯水
├── ELECTRICAL (电气系统) - 供配电、应急电源、照明
├── AUTOMATION (智能化系统) - 楼宇自控、能源管理、安防
└── MEDICAL_GAS (医疗气体系统) - 氧气、压缩空气、负压吸引
```

## 六层空间模型

从宏观到微观的空间层级：

```
Site (站点) → Building (建筑) → Floor (楼层)
    → Zone (区域) → Room (房间) → SubSpace (子空间)
```

**示例**: `SITE-001-BLDG01-L3-ZMED-OP-ROOM301`
- 站点001 → 建筑01 → 3层 → 门诊医疗区 → 301房间

## 九Agent协作体系

9个专业代理分工协作完成CIM建模：

| Agent | 角色 | 核心职责 |
|-------|------|----------|
| Agent-01 | 系统拓扑建模师 | HVAC/电气/给排水等系统拓扑 |
| Agent-02 | 空间本体建模师 | 建筑→楼层→区域→房间层级 |
| Agent-03 | 设备本体建模师 | 设备分类、属性、关系 |
| Agent-04 | 流动模型建模师 | 物质/能量/信息流动路径 |
| Agent-05 | 系统-空间耦合建模师 | 系统与空间的关联关系 |
| Agent-06 | 控制系统建模师 | 传感器、执行器、控制回路 |
| Agent-07 | 计量体系建模师 | 计量点、能耗分摊规则 |
| Agent-08 | 运维管理建模师 | 告警、工单、维护计划 |
| Agent-09 | 模型整合验证师 | 一致性、完整性验证 |

## 关键术语速查

| 术语 | 说明 |
|------|------|
| **CIM** | Common Information Model，统一领域模型 |
| **PIM** | Platform Independent Model，平台无关模型 |
| **PSM** | Platform Specific Model，平台特定模型 |
| **BIM** | Building Information Modeling，建筑信息模型 |
| **IFC** | Industry Foundation Classes，工业基础类（BIM标准） |
| **BMS** | Building Management System，楼宇管理系统 |
| **EMS** | Energy Management System，能源管理系统 |
| **AHU** | Air Handling Unit，空调机组 |
| **FCU** | Fan Coil Unit，风机盘管 |
| **DDC** | Direct Digital Control，直接数字控制 |
