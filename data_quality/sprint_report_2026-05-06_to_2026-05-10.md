## 一、架构重构 — ISO 19650 四层本体 (Day 1-2)

### 1.1 从扁平到分层

v3.4（M1 基线）是 Agent-01~08 输出的扁平合并。v4.0 重构为 ISO 19650 对齐的分层架构：

```
_index_v4.ttl (总入口, owl:imports 16模块)
│
├── Layer 0 — 基础本体 (layer0_foundational.ttl, 717行)
│   BFO 2020 对齐: Continuant/Occurrent/Quality/Function/Role
│   设施生命周期: Concept→SD→DD→Tender→Construction→Commissioning→Operation
│   里程碑: DesignApproval / IDM / ConstructionCompletion / Handover
│
├── Layer 1 — 概念本体 (layer1_conceptual.ttl, 1,142行)
│   介质层级(Medium): 30+类, 覆盖空气/水/医气/电力/信息
│   连接点模型(ConnectionPoint): ASHRAE 223P 对齐
│   数据点层级(Point): Brick 对齐, Sensor/Setpoint/Command/Alarm
│   设备扩展: 80+类, 含 P0/P1/P2 末端修复
│   空间扩展: 30+类, 从临床核心到行政公共
│   流动模型(FlowPath): 31类, MassFlow/EnergyFlow/InformationFlow
│
├── Layer 2 — 参考本体 (layer2_reference.ttl, 344行)
│   ISO 19650 信息管理: EIR/AIR/BEP/IDM/CDE
│   分类体系: Uniclass/OmniClass/GB 51269
│   标准库: GB50333/WS435/IEC60364-710 等12部
│   产品数据模板: ISO 23386/23387
│
├── Layer 3 — 设计本体 (layer3_design.ttl, 503行)
│   性能准则: 洁净室换气/压差/温湿度, GB50333硬编码实例
│   系统规格: HVAC/电气/医气/给排水
│   负荷计算: CoolingLoad/HeatingLoad/ElectricalLoad
│
├── Layer 4 — 运营本体 (layer4_operational.ttl, 646行)
│   资产台账 + SOSA/SSN传感观测 + PM/CM/PdM维护管理
│   告警系统 + 能耗统计 + KPI(MTBF/MTTR/EUI)
│
└── Bridge ×4 (1,420行)
    bridge_brick.ttl:     Brick 1.3 (~60 equivalentClass)
    bridge_ashrae223p.ttl: 223P 介质/连接点全层级
    bridge_ifc.ttl:        IFC4/IFC2X3 空间/系统/设备
    bridge_fso.ttl:        FSO v0.1.0 35设备+17属性+SPARQL双向推导
```

### 1.2 BFO 2020 基础层

关键设计决策——区分持续体与发生体：

| BFO 范畴 | CIM 对应 | 意义 |
|---------|---------|------|
| Object (BFO_0000030) | Equipment, Pipe, Duct | 物理设备在时间中持续存在 |
| Site (BFO_0000029) | Space, Room, Zone | 空间场所无质量 |
| Process (BFO_0000015) | FluidFlowProcess, FacilityLifecycleProcess | 过程在时间中展开 |
| ProcessBoundary (BFO_0000035) | DesignApproval, Handover | 阶段间里程碑 |
| Quality (BFO_0000019) | FlowRate, Pressure, Temperature | 依赖性质量 |
| Function (BFO_0000034) | CoolingFunction, PumpingFunction | 设备功能 |
| History (BFO_0000182) | FacilityHistory | 全过程聚合 |

FlowPath（管网拓扑）= 持续体；FluidFlowProcess（实际流动）= 发生体。
