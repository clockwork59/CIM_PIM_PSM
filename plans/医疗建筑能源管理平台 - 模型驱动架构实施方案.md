# 医疗建筑能源管理平台 - 模型驱动架构实施方案

## 一、方法论框架

### 1.1 CIM-PIM-PSM 三层模型架构

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         模型驱动架构（MDA）                               │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  CIM - 计算无关模型 (Computation Independent Model)              │   │
│  │  ─────────────────────────────────────────────────────────────  │   │
│  │  · 纯业务视角，不涉及任何技术实现                                 │   │
│  │  · 领域本体（Ontology）：概念、关系、规则                         │   │
│  │  · 业务流程模型、业务规则模型                                     │   │
│  │  · 可被业务专家理解和验证                                         │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                              ↓ 模型转换                                 │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  PIM - 平台无关模型 (Platform Independent Model)                 │   │
│  │  ─────────────────────────────────────────────────────────────  │   │
│  │  · 技术视角，但不绑定特定平台/技术栈                              │   │
│  │  · 逻辑数据模型、API契约模型                                      │   │
│  │  · 组件模型、服务模型                                             │   │
│  │  · 可被技术架构师理解                                             │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                              ↓ 模型转换                                 │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  PSM - 平台特定模型 (Platform Specific Model)                    │   │
│  │  ─────────────────────────────────────────────────────────────  │   │
│  │  · 绑定特定技术栈和平台                                           │   │
│  │  · 物理数据模型（DDL）、具体API实现                               │   │
│  │  · 部署模型、配置模型                                             │   │
│  │  · 可直接生成可执行代码                                           │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 3.2 设备本体模型 (Equipment Ontology)

```yaml
# 设备通用本体模型
Equipment_Ontology:

  # 核心概念类
  Core_Concepts:
    Equipment:
      definition: "执行特定功能的物理装置"
      attributes:
        - identifier         # 唯一标识
        - name              # 名称
        - classification    # 分类
        - manufacturer      # 制造商
        - model             # 型号
        - serial_number     # 序列号
        - installation_date # 安装日期
        - warranty_expiry   # 质保到期
        - lifecycle_status  # 生命周期状态
    
    Component:
      definition: "设备的组成部分"
      parent: Equipment
      attributes:
        - parent_equipment  # 所属设备
        - component_type    # 组件类型
      
    System:
      definition: "由多个设备组成的功能系统"
      attributes:
        - system_type       # 系统类型
        - contained_equipment  # 包含的设备
        - serving_spaces    # 服务的空间
      
  # 关系类型
  Relationships:
    contains:
      domain: System
      range: Equipment
      cardinality: 1:N
    
    component_of:
      domain: Component
      range: Equipment
      cardinality: N:1
    
    serves:
      domain: Equipment
      range: Space
      cardinality: N:N
    
    located_in:
      domain: Equipment
      range: Space
      cardinality: N:1
    
    connected_to:
      domain: Equipment
      range: Equipment
      cardinality: N:N
      properties:
        - connection_type   # 连接类型(管道/电缆/控制)
        - medium            # 介质
        - flow_direction    # 流向
      
    metered_by:
      domain: Equipment
      range: Meter
      cardinality: N:N
    
    controlled_by:
      domain: Equipment
      range: Controller
      cardinality: N:N
    
  # 状态模型
  State_Model:
    Operational_State:
      values:
        - RUNNING           # 运行中
        - STOPPED           # 停止
        - STANDBY           # 待机
        - FAULT             # 故障
        - MAINTENANCE       # 维护中
        - OFFLINE           # 离线
      
    Lifecycle_State:
      values:
        - PLANNED           # 规划中
        - INSTALLING        # 安装中
        - COMMISSIONING     # 调试中
        - OPERATIONAL       # 运营中
        - DECOMMISSIONED    # 已退役
```

### 3.3 具体设备类型CIM示例 - 冷水机组

```yaml
Chiller_CIM:

  概念定义:
    名称: 冷水机组 (Chiller)
    定义: 通过制冷循环将热量从冷冻水转移到冷却水的制冷设备
    上级分类: 冷源设备 (Chiller_Plant_Equipment)
  
  子类型:
    - 离心式冷水机组 (Centrifugal_Chiller)
    - 螺杆式冷水机组 (Screw_Chiller)
    - 涡旋式冷水机组 (Scroll_Chiller)
    - 吸收式冷水机组 (Absorption_Chiller)
    - 磁悬浮冷水机组 (Magnetic_Bearing_Chiller)
  
  静态属性:
    铭牌属性:
      - rated_cooling_capacity    # 额定制冷量 (kW/RT)
      - rated_power              # 额定功率 (kW)
      - rated_cop                # 额定COP
      - rated_iplv               # 综合部分负荷性能系数
      - refrigerant_type         # 制冷剂类型
      - refrigerant_charge       # 制冷剂充注量 (kg)
      - chw_flow_rate           # 冷冻水流量 (m³/h)
      - cw_flow_rate            # 冷却水流量 (m³/h)
      - chw_pressure_drop       # 冷冻水侧压降 (kPa)
      - cw_pressure_drop        # 冷却水侧压降 (kPa)
      - min_load_ratio          # 最小负载率 (%)
      - max_load_ratio          # 最大负载率 (%)
    
    安装属性:
      - installation_location    # 安装位置
      - installation_date        # 安装日期
      - commissioning_date       # 调试日期
    
  动态属性(运行参数):
    状态参数:
      - run_status              # 运行状态
      - run_mode                # 运行模式(制冷/制热/待机)
      - alarm_status            # 告警状态
    
    能效参数:
      - current_load            # 当前负载 (kW/RT)
      - load_ratio              # 负载率 (%)
      - input_power             # 输入功率 (kW)
      - current_cop             # 当前COP
      - accumulated_energy      # 累计电耗 (kWh)
      - accumulated_cooling     # 累计冷量 (kWh)
      - run_hours               # 累计运行小时
      - start_count             # 累计启动次数
    
    冷冻水侧:
      - chw_supply_temp         # 冷冻水出水温度 (℃)
      - chw_return_temp         # 冷冻水回水温度 (℃)
      - chw_delta_t             # 冷冻水温差 (℃)
      - chw_flow                # 冷冻水流量 (m³/h)
      - chw_supply_pressure     # 冷冻水出水压力 (kPa)
      - chw_return_pressure     # 冷冻水回水压力 (kPa)
    
    冷却水侧:
      - cw_supply_temp          # 冷却水进水温度 (℃)
      - cw_return_temp          # 冷却水出水温度 (℃)
      - cw_delta_t              # 冷却水温差 (℃)
      - cw_flow                 # 冷却水流量 (m³/h)
    
    压缩机参数:
      - compressor_status       # 压缩机状态
      - suction_pressure        # 吸气压力 (kPa)
      - discharge_pressure      # 排气压力 (kPa)
      - suction_temp            # 吸气温度 (℃)
      - discharge_temp          # 排气温度 (℃)
      - oil_pressure            # 油压 (kPa)
      - oil_temp                # 油温 (℃)
      - motor_current           # 电机电流 (A)
      - motor_temp              # 电机温度 (℃)
      - vane_position           # 导叶开度 (%) [离心机]
      - slide_valve_position    # 滑阀位置 (%) [螺杆机]
    
    振动与诊断:
      - vibration_level         # 振动等级 (mm/s)
      - bearing_temp            # 轴承温度 (℃)
    
  控制点位:
    设定参数:
      - chw_supply_setpoint     # 冷冻水出水设定 (℃)
      - load_limit_setpoint     # 负载限制设定 (%)
      - demand_limit            # 需量限制 (kW)
    
    控制命令:
      - start_command           # 启动命令
      - stop_command            # 停止命令
      - load_up_command         # 加载命令
      - load_down_command       # 减载命令
    
  关联关系:
    上游设备:
      - chilled_water_pump      # 冷冻水泵
      - condenser_water_pump    # 冷却水泵
      - cooling_tower           # 冷却塔
    
    下游设备:
      - secondary_pump          # 二次泵
      - air_handling_unit       # 空调机组
    
    辅助设备:
      - vfd                     # 变频器(如有)
      - soft_starter            # 软启动器
    
    计量设备:
      - power_meter             # 电表
      - cooling_meter           # 冷量计
      - chw_flow_meter          # 冷冻水流量计
    
    控制系统:
      - chiller_controller      # 冷机本地控制器
      - plant_controller        # 冷站群控控制器
    
  业务规则:
    启动条件:
      - 冷冻水泵已运行
      - 冷却水泵已运行
      - 冷却塔已运行
      - 冷冻水流量满足最小要求
      - 无一级告警
    
    运行约束:
      - 最小运行时间: 10分钟
      - 最小停机时间: 15分钟
      - 启动间隔: 20分钟
      - 负载率范围: [min_load_ratio, max_load_ratio]
    
    告警规则:
      - COP偏低: current_cop < rated_cop * 0.75
      - 冷冻水温差过小: chw_delta_t < 3℃
      - 压缩机过载: motor_current > rated_current * 1.1
      - 排气温度过高: discharge_temp > 85℃
      - 油温过高: oil_temp > 65℃
```
