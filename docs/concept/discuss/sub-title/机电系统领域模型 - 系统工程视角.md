# 机电系统领域模型 - 系统工程视角

## 一、技术系统通用元模型 (Meta-Model)

### 1.1 系统拓扑网络元模型

```yaml
Technical_System_Meta_Model:
  
  定义: |
    任何技术系统都可以抽象为一个有向图（Directed Graph），
    其中节点代表功能实体，边代表介质/能量/信息的传输路径。
    
  核心概念:
    
    # ========== 节点层 ==========
    Node（节点）:
      定义: 系统中执行特定功能的实体
      分类:
        Source_Node（源节点）:
          定义: 系统的能量/介质输入端，是流动的起点
          特征:
            - 向系统注入能量或介质
            - 可以是外部边界（如市电、市政水）
            - 也可以是转换设备的输出（如冷机产生冷量）
          示例: 变压器、冷机、锅炉、水泵进口、新风口
          
        Sink_Node（末端节点）:
          定义: 系统的能量/介质消耗端，是流动的终点
          特征:
            - 消耗或转换能量/介质
            - 直接服务于最终用途
          示例: 风机盘管、照明灯具、医疗设备、排风口
          
        Distribution_Node（输配节点）:
          定义: 进行分配、汇集、调节的中间节点
          子类型:
            Junction（汇合点）:
              定义: 多路输入汇聚为一路输出
              示例: 集水器、汇流排
              
            Splitter（分配点）:
              定义: 一路输入分配为多路输出
              示例: 分水器、配电柜、母线槽分接
              
            Regulator（调节点）:
              定义: 对流量/压力/电压等进行调节
              示例: 调节阀、减压阀、变频器
              
            Transformer（转换点）:
              定义: 改变介质形态或能量品位
              示例: 换热器、变压器、AHU
              
    # ========== 边层 ==========
    Edge（边/连接）:
      定义: 节点之间的传输路径
      属性:
        - direction: 流向（单向/双向）
        - medium: 传输介质
        - capacity: 传输能力
        - status: 状态（通/断/调节中）
        
      分类:
        Trunk（干线）:
          定义: 主要传输通道，承载大流量
          示例: 高压母线、冷冻水主管、送风主管
          
        Branch（支线）:
          定义: 从干线分出的次级通道
          示例: 楼层配电、楼层水平管、支风管
          
        Terminal_Connection（末端连接）:
          定义: 连接到末端设备的最后一段
          示例: 风机盘管接管、灯具线路
          
    # ========== 路径层 ==========
    Path（路径）:
      定义: 从源到末端的完整流动通道
      组成: 有序的节点和边序列
      类型:
        Supply_Path（供应路径）: 从源到末端
        Return_Path（回流路径）: 从末端返回（闭环系统）
        
    # ========== 区域层 ==========
    Zone（分区）:
      定义: 具有共同特征的节点和边的集合
      划分依据:
        - 物理位置（楼层、区域）
        - 功能用途（手术区、病房区）
        - 控制边界（同一控制回路）
        - 计量边界（同一计量单元）
```

### 1.2 拓扑关系模型

```yaml
Topology_Relationships:

  # 节点间拓扑关系
  Node_Relations:
    
    upstream_of（上游于）:
      定义: A是B的介质/能量来源
      传递性: 是
      示例: 冷机 upstream_of 空调机组
      
    downstream_of（下游于）:
      定义: A接收来自B的介质/能量
      传递性: 是
      反关系: upstream_of
      
    parallel_to（并联于）:
      定义: A和B共享同一上游和下游
      示例: 两台并联冷机
      
    series_with（串联于）:
      定义: A的输出直接是B的输入
      示例: 一次泵 series_with 二次泵
      
    backup_for（备用于）:
      定义: A是B的冗余备份
      示例: 2号冷机 backup_for 1号冷机
      
  # 系统层次关系
  System_Hierarchy:
    
    contains（包含）:
      定义: 系统包含子系统或设备
      层级: System → Subsystem → Equipment → Component
      
    serves（服务于）:
      定义: 系统为空间/功能提供服务
      示例: 冷站系统 serves 全院空调
      
    depends_on（依赖于）:
      定义: 系统运行依赖另一系统
      示例: 冷机 depends_on 供电系统
```

### 1.3 系统流动模型

```yaml
Flow_Model:
  
  定义: 描述能量/介质在拓扑网络中的流动特性
  
  Flow_Types（流动类型）:
    
    Energy_Flow（能量流）:
      类型:
        - Electrical（电能）: 单位 kW, kWh
        - Thermal_Cooling（冷量）: 单位 kW, kWh, RT
        - Thermal_Heating（热量）: 单位 kW, kWh
        - Pressure_Energy（压力能）: 单位 kPa, m
        
    Mass_Flow（质量流）:
      类型:
        - Water（水）: 单位 m³/h, L/s
        - Air（空气）: 单位 m³/h, L/s
        - Steam（蒸汽）: 单位 kg/h, t/h
        - Gas（燃气）: 单位 m³/h
        - Refrigerant（制冷剂）: 单位 kg/h
        
    Information_Flow（信息流）:
      类型:
        - Control_Signal（控制信号）
        - Sensor_Data（传感数据）
        - Alarm_Event（告警事件）
        
  Flow_Properties（流动属性）:
    - magnitude: 流量大小
    - direction: 流动方向
    - quality: 品质参数（温度、压力、电压等）
    - state: 状态（稳态、暂态）
    
  Conservation_Laws（守恒定律）:
    节点守恒:
      定义: 进入节点的流量 = 流出节点的流量 + 节点存储变化
      应用: 分水器、配电柜的流量平衡
      
    路径守恒:
      定义: 沿路径各点流量相等（无分支时）
      应用: 管道流量、电缆电流
```

### 2.3 空调风系统拓扑

```yaml
Equipment_Model_Hierarchy:
```
