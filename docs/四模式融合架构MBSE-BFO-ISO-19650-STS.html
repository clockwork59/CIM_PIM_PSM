模式二：BFO 动态本体

持续体(Continuant)与发生体(Occurrent)的范畴区分

C

持续体 Continuant

在时间中持续存在的实体，"什么存在"

对象 (Object)

AirHandlingUnit, Chiller — AHU-001从安装到退役始终是"同一台设备"

场所 (Site)

OperatingRoom, ICU — OR-01是非物质实体(空间)

质量 (Quality)

FlowRateQuality — 某一瞬间的流速值

功能 (Function)

CoolingFunction — 冷机的冷却功能(是其存在的目的)

O

发生体 Occurrent

在时间中展开的过程，"什么发生"

过程 (Process)

FluidFlowProcess, MaintenanceActivity — 冷冻水流动、维保作业

过程边界 (ProcessBoundary)

HandoverMilestone — PIM->AIM信息移交瞬间

时间区域 (TemporalRegion)

OperationalPeriod — 运营时段

关键创新：Flow的双重性

FlowPath (持续体)

  • • 描述: 管路拓扑连接关系
  • • 属性: 设计流量 180 m³/h
  • • 生命期: 建筑使用期内恒定
  • • 来源: IFC/设计文档
  • • 用途: 设计验证(检查拓扑)

FluidFlowProcess (发生体)

  • • 描述: 介质在管路中的实际流动
  • • 属性: 当前流量 165 m³/h
  • • 生命期: 有开始时间和结束时间
  • • 来源: BAS/传感器
  • • 用途: 运营监控(检查流态)
使跨Named Graph（graph/pset设计参数 vs graph/bas/t0实时读数）的比较分析成为可能
