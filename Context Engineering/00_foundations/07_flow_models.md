# 流动模型：物质-能量-信息的三流合一

**文档 ID**: `CIMU-FOUND-07-FLOW`
**版本**: v1.0
**最后更新**: 2025-12-07

---

## 概述

医疗建筑中的机电系统本质上是处理各种"流动"的系统。CIM 流动模型通过统一的框架描述物质流（水、空气、气体）、能量流（冷热、电力）和信息流（控制信号、状态反馈），实现系统的整体理解、仿真与优化。

---

## 三层流动模型

```
┌─────────────────────────────────────────┐
│  Layer 1: 物质流 (Mass Flow)            │
│  水、空气、气体、蒸汽                     │
├─────────────────────────────────────────┤
│  Layer 2: 能量流 (Energy Flow)          │
│  冷热能量、电能、机械能                   │
├─────────────────────────────────────────┤
│  Layer 3: 信息流 (Information Flow)     │
│  控制信号、传感器数据、状态信息           │
└─────────────────────────────────────────┘
```

---

## Layer 1: 物质流（Mass Flow）

### 定义

物质流是看得见、摸得着的物理介质流动。

### 类型

#### 1.1 水流（Water Flow）

**冷冻水 (CHW - Chilled Water)**
```yaml
介质类型: CHW
流动路径:
  源: 冷水机组蒸发器
  路径: 冷冻水泵 → 分水器 → 支管 → 末端设备 → 集水器 → 返回冷机
温度参数:
  供水: 7°C
  回水: 12°C
  温差: 5K
压力参数:
  工作压力: 1.0 MPa
流量参数:
  设计流量: 180 m³/h
  流速: 1.5 ~ 2.5 m/s
```

**热水 (HW - Hot Water)**
```yaml
介质类型: HW
用途: 空调采暖、生活热水
温度参数:
  空调热水: 45°C / 40°C (供/回)
  生活热水: 60°C / 50°C (供/回)
```

**冷却水 (CW - Condenser Water)**
```yaml
介质类型: CW
用途: 冷却制冷设备冷凝器
温度参数:
  供水: 32°C (从冷却塔)
  回水: 37°C (回冷却塔)
温差: 5K
```

**生活给水 (Domestic Cold Water)**
```yaml
介质类型: DCW
用途: 生活用水、饮用
压力:
  市政压力: 0.2 ~ 0.4 MPa
  加压供水: 0.4 ~ 0.6 MPa
水质: 符合 GB 5749
```

#### 1.2 空气流（Air Flow）

**送风 (Supply Air)**
```yaml
介质类型: SA
处理过程: 过滤 → 冷却/加热 → 加湿 → 送风
温度参数:
  夏季: 14 ~ 16°C (经空调机组处理后)
  冬季: 28 ~ 32°C (经空调机组处理后)
风量指标:
  新风量: 按人员计算 (30 ~ 50 m³/h·pax)
  总风量: 按换气次数计算
  送风量 = 回风量 + 排风量 + 新风量
```

**回风 (Return Air)**
```yaml
介质类型: RA
处理方式:
  - 部分回风: 与新风混合后重新处理 (节能)
  - 全部回风: 循环使用 (无污染物)
  - 无回风: 全新风 (有污染风险，如传染病区)
典型比例: 70% 回风 + 30% 新风
```

**排风 (Exhaust Air)**
```yaml
介质类型: EA
排风类型:
  - 一般排风: 卫生间、设备间
  - 工艺排风: 实验室、检验科
  - 污染排风: 感染病房、负压隔离区
排风要求:
  - 不应短路 (避免与新风混合)
  - 污染空气应过滤/消毒后排放
  - 排风量应根据房间压差控制
```

**新风 (Fresh Air / Outdoor Air)**
```yaml
介质类型: OA
来源: 室外空气
处理要求:
  - 过滤: G4 → F7 (初效 → 中效)
  - 预处理: 夏季预冷，冬季预热
新风量标准:
  - 一般诊室: 3 ACH (Air Changes per Hour)
  - 手术室: 15 ACH
  - 传染病房: 12 ACH (全新风)
```

#### 1.3 医用气体流（Medical Gas Flow）

**氧气 (OXY - Medical Oxygen)**
```yaml
介质类型: OXY
供应压力: 0.4 ~ 0.6 MPa (工作压力)
使用压力: 0.4 MPa (终端压力)
纯度: ≥ 99.5%
露点: ≤ -23°C
流量:
  单个终端: 10 ~ 100 L/min
  手术台: 40 ~ 100 L/min
  麻醉机: 10 ~ 20 L/min
```

**压缩空气 (AIR - Medical Compressed Air)**
```yaml
介质类型: AIR
供应压力: 0.6 ~ 0.8 MPa
露点: ≤ -23°C
含油量: ≤ 0.1 mg/m³
颗粒物: ≤ 1 mg/m³
流量:
  通气: 10 ~ 60 L/min
  仪器驱动: 根据设备要求
```

**负压吸引 (VAC - Medical Vacuum)**
```yaml
介质类型: VAC
负压值: -0.04 ~ -0.09 MPa (相对压力)
流量:
  单个终端: 30 ~ 80 L/min
  手术台: 80 L/min
过滤器: 必须设置细菌过滤器
排放: 高空排放，远离新风取风口
```

#### 1.4 蒸汽流（Steam Flow）

```yaml
介质类型: STM
用途:
  - 加湿: 冬季空调加湿
  - 消毒: 中心供应室
  - 洗衣房: 洗衣设备
压力等级:
  - 高压蒸汽: 0.8 MPa (消毒)
  - 低压蒸汽: 0.2 MPa (加湿)
温度: 175°C (0.8 MPa饱和蒸汽)
```

## Layer 2: 能量流（Energy Flow）

### 定义

能量流是物质流携带的能量传递，或直接的能量传输。

### 类型

#### 2.1 冷能流（Cooling Energy Flow）

**能量载体**: 冷冻水、制冷剂、空气

**能量计算公式**:
```
Q = m × c × ΔT

Q: 制冷量 (kW)
m: 质量流量 (kg/s)
c: 比热容 (kJ/kg·K)
ΔT: 温差 (K)

冷冻水: Q = m(kg/s) × 4.18(kJ/kgK) × (12-7)(K)
空气: Q = ρ(kg/m³) × V(m³/s) × 1.01(kJ/kgK) × ΔT(K)
```

**示例**: 冷冻水空调系统
```yaml
源: 冷水机组蒸发器
  制冷量: 1055 kW
  供水温度: 7°C
能量传递路径:
  - 冷冻水泵 (输入电能，提高压力)
  - 分水器 (分配流量)
  - AHU (吸收室内空气热量)
汇: 室内热量 (被移除)

能效比:
  COP: 5.7 (制冷输出 / 电输入)
```

#### 2.2 热能流（Heating Energy Flow）

**能量载体**: 热水、蒸汽、电加热

**计算示例**: 热水采暖
```yaml
热源: 锅炉
  制热量: 2000 kW
  供水温度: 85°C
能量传递:
  - 热水泵 (输送)
  - 分水器 (分配)
  - FCU (向室内放热)
  - 集水器 (收集回水)
回水温度: 60°C
```

#### 2.3 电能流（Electric Power Flow）

```
电源 → 变压器 → 低压配电柜 → 配电箱 → 设备
(10kV)   (380V)      (380V)        (220V)
```

**能量流程示例**: MRI 设备供电
```yaml
电源输入:
  - 主供电: 三相380V，150kVA
  - UPS供电: 三相380V，100kVA (备用)

能量转换:
  - 整流器: 交流380V → 直流±300V
  - 磁体电源: DC ±300V → 磁体电流 (1000A)
  - 梯度放大器: 高功率脉冲 (100kW peak)
  - 射频放大器: RF 功率 (35kW)

能耗特点:
  - 连续功耗: 60kW (磁体冷却)
  - 脉冲功耗: 100kW peak (扫描时)
  - 功率因数: 0.9 (需要补偿)
```

**电能质量要求**:
- 电压稳定: ±5%
- 频率稳定: 50Hz ±0.5%
- 谐波畸变: < 5%
- 备用电源: 10ms 切换

#### 2.4 机械能流（Mechanical Energy Flow）

**表现形式**:
- 风机: 电能 → 空气动能 (压力能)
- 水泵: 电能 → 液体动能
- 压缩机: 电能 → 制冷剂压力能

**风机示例**:
```yaml
电机功率: 15 kW
效率: 85%
机械能输出: 12.75 kW

空气动力:
  - 静压: 500 Pa
  - 风量: 12000 m³/h
  - 风机效率: 70%
```

## Layer 3: 信息流（Information Flow）

### 定义

信息流是控制信号、传感器数据、状态反馈等信息的传递。

### 类型

#### 3.1 控制信号流（Control Signal Flow）

**类别**:
- **模拟信号 (Analog)**: 4-20mA, 0-10V
- **数字信号 (Digital)**: 开关信号
- **网络信号 (Network)**: BACnet, Modbus, LonWorks

**示例**: 空调机组控制
```yaml
控制路径:
  传感器层:
    - T_Supply: AI-301 (供水温度, 4-20mA)
    - T_Return: AI-302 (回水温度, 4-20mA)
    - P_Supply: AI-303 (供水压力, 4-20mA)
    - Flow: AI-304 (流量, 4-20mA)

  控制器层 (DDC):
    - 接收传感器信号 (模拟输入)
    - 执行 PID 计算
    - 输出控制命令

  执行器层:
    - Valve_CHW: AO-301 (冷水阀, 0-10V)
    - Valve_HW: AO-302 (热水阀, 0-10V)
    - Pump_Enable: DO-301 (水泵启停)

控制策略:
  - 串级控制: 根据回风温度调节送风温度设定值
  - 根据送风温度调节冷热水阀开度
  - 根据末端需求调节水泵频率
```

#### 3.2 传感器数据流（Sensor Data Flow）

**数据特征**:
- 采样频率: 1秒 ~ 10分钟（根据参数变化速率）
- 数据精度: 根据仪表精度
- 传输延迟: < 100ms (实时控制)

**示例**: BMS 数据采集
```yaml
数据点示例:
  - CHW_Supply_Temp:
      point_name: "空调冷冻水供水温度"
      point_type: AI (模拟输入)
      unit: °C
      range: 0 ~ 20
      accuracy: ±0.5°C
      scan_rate: 10秒
      data_source: DDC-3F-01
      storage: "历史数据库 (InfluxDB)"

  - CHWP_Status:
      point_name: "冷冻水泵运行状态"
      point_type: BI (二进制输入)
      values: [0:停止, 1:运行]
      scan_rate: 1秒
      alarm_enabled: True
"
```

#### 3.3 告警信息流（Alarm Flow）

**告警等级**:
- **紧急 (Critical)**: 生命安全, 立即响应
- **重要 (High)**: 设备停运, 4小时响应
- **一般 (Medium)**: 性能下降, 24小时响应
- **信息 (Low)**: 状态变化, 记录即可

**告警流程**:
```
告警触发 → 本地确认 → 上级通知 → 工单派发 → 处理 → 关闭
  ↓
抑制规则？→ 延迟发送？→ 升级规则？→ 短信/电话？
```

**示例**: 冷机故障告警
```yaml
告警流程:
  触发条件:
    - 冷机状态从 RUNNING → FAULT
    or
    - 冷冻水流量 < 80% 额定流量

  告警等级: HIGH

  通知路径:
    0分钟: BMS 屏幕弹出
    0分钟: 发送给值班工程师 (APP推送)
    5分钟: 发送给运维主管 (短信)
    15分钟: 升级到医院后勤总监 (电话)

  处理要求:
    - 15分钟: 现场确认
    - 30分钟: 启动备用设备
    - 4小时: 修复或制定修复计划

  影响评估:
    - 影响区域: "3层门诊医疗区"
    - 影响面积: 2400 m²
    - 影响人数: ~120人
    - 风险等级: MEDIUM (有备用系统)
```

#### 3.4 维护信息流（Maintenance Flow）

**维护流程**:
```
计划 → 工单创建 → 派工 → 执行 → 验收 → 记录
  ↓
基于时间的计划性维护 (PM)
基于状态的预测性维护 (PdM)
基于故障的修复性维护 (CM)
```

**示例**: 冷机季度维护
```yaml
维护工单:
  工单编号: WO-2025-Q4- CHL-19XR-001
  设备: CH-3F-01 (1号冷机)
  维护类型: PM (Preventive Maintenance)
  维护周期: QUARTERLY (季度)
  计划日期: 2025-12-15

  维护内容:
    - 检查冷冻油油位和油质
    - 更换油过滤器
    - 检查制冷剂压力和泄漏
    - 清洁蒸发器、冷凝器
    - 检查控制柜接线
    - 测试安全保护装置

  所需备件:
    - 油过滤器: 型号 OF-123, 数量 1
    - 冷冻油: 型号 L-46, 数量 5L

  执行人员: 张师傅 (资深冷机技师)
  预计工时: 4小时

  完工记录:
    实际日期: 2025-12-15
    实际工时: 3.5小时
    发现异常: "冷媒压力略低于标准，已补充100kg"
    下次维护: 2026-03-15
```

## 三流融合：以空调系统为例

### 完整流程示例

```
时间: 上午 10:00
室外温度: 35°C
负荷: 人员 100人，新风需求大

物质流 (过程):
  ① 冷冻水流动: 冷水机 → 水泵 → AHU
     流量: 150 m³/h
     温度: 7°C (供) / 12°C (回)

  ② 空气流动: AHU → 风管 → 房间
     风量: 20000 m³/h
     温度: 16°C (送风)

能量流 (过程):
  ① 电输入: 冷机耗电 185 kW + 水泵耗电 30 kW
     总输入: 215 kW

  ② 制冷输出: 1055 kW (移除室内热量)
     COP: 5.7 (1055/185)

  ③ 输配损耗: 水泵机械能 30 kW
      输送系数: 35 (1055/30)

信息流 (过程):
  ① 传感器测量:
     - T_supply: 6.8°C (AI-301)
     - T_return: 12.3°C (AI-302)
     - Flow: 148 m³/h (AI-303)
     - P_supply: 0.52 MPa (AI-304)

  ② 控制器计算:
     实际制冷量 = m × ΔT × c
                = 41 kg/s × 5.5K × 4.18
                = 944 kW

     负荷率 = 944 / 1055 = 89%

     PID 计算: 阀门开度应调整到 85%

  ③ 执行器动作:
     - VLV_CHW → 85% (AO-301)
     - VLV_HW → 0% (AO-302, 夏季不加热)
     - FAN → 100% (DO-301)

  ④ 数据记录与监控:
     - 存入历史数据库
     - 更新监控画面
     - 计算实时能耗

  ⑤ 优化建议 (基于 AI):
     "冷却水温偏低，可提高冷凝器设定温度 1°C，预计节能 3%"
```

## 流动模型的数学表达

### 物质流平衡方程

```
质量守恒: Σ(流入质量) = Σ(流出质量) + Σ(储存变化)

对于稳态流动:
  Σ(流入) = Σ(流出)

示例: 冷冻水平衡
  m_chw_supply = m_ahu_1 + m_ahu_2 + ... + m_ahu_n
  (进入分水器的流量 = 各末端支路流量之和)
```

### 能量平衡方程

```
能量守恒: Q_in + W_in = Q_out + W_out + ΔU

对于空调系统:
  Q_cooling = Σ(m_i × c × ΔT_i) + Σ(P_fan) + Σ(P_pump)

示例: AHU 能量平衡
  Q_cooling = m_chw × c × (T_return - T_supply)  (冷水供冷)
              + m_air × h × (Δω)                  (加湿)
              - P_fan                               (部分风机功耗转化为热能)
```

### 流动网络方程（Flow Network）

```
节点平衡方程: A × m = b

A: 节点-支路关联矩阵
m: 支路流量向量 [kg/s]
b: 节点注入向量 [kg/s]

示例: 3节点网络
     支路1   支路2   支路3
节点1 [  1      1      0  ]  [m1]   [ 10 ]  (源点)
节点2 [ -1      0      1  ]  [m2] = [  0 ]  (中间点)
节点3 [  0     -1     -1  ]  [m3]   [ -10 ] (汇点)
```

## 流动模型的应用

### 1. 故障诊断

**场景**: 某房间温度偏高

**流动分析**:
```
Step 1: 检查空气流
  - 送风量是否足够? (与设计值对比)
  - 房间压差是否正常? (是否有漏风)

Step 2: 检查物质流 (冷冻水)
  - FCU 水阀开度是否足够?
  - 冷冻水温度是否正常?
  - 水流量是否达到设计值?

Step 3: 检查能量流
  - FCU 制冷能力是否衰减?
  - 房间热负荷是否超过设计?

Step 4: 检查信息流
  - 传感器读数是否准确?
  - 控制指令是否正确送达?
```

### 2. 能耗分析

**场景**: 手术室空调能耗异常高

**流动追踪**:
```
Input: 电能 → 冷机、水泵、风机
        ↓
Process: 电能 → 冷能 (COP = 5.7)
         ↓
         输配 (水泵效率 70%)
         ↓
         空气输送 (风机效率 65%)
         ↓
Output: 移除室内热量

Losses: 冷凝器排热、管道损失、风道泄漏

Opportunities:
  - 冷却水温度设定可否提高? (影响冷凝温度)
  - 水泵变频控制是否合理? (避免过流量)
  - 新风量是否过量? (根据 CO2 调节)
  - 送风温度设定可否优化? (避免再热损失)
```

### 3. 系统优化

**场景**: 冷冻水系统优化

**流动优化**:
```yaml
优化前:
  供回温差: 4K (7°C供水，11°C回水)
  流量: 187.5 m³/h
  水泵功率: 37 kW

优化目标: 提高温差至 5K (标准设计)
  新流量: 150 m³/h (流量降低 20%)
  新水泵功率: 23.6 kW (功率降低 36%)

控制策略:
  - 根据末端最不利阀门开度调节水泵频率
  - 保持所有阀门开度在 80% ~ 95%
  - 避免阀门过小导致节流损失

预期节能: 13.4 kW (每年节约 117,000 kWh)
```

## 小结

流动模型通过统一描述物质流、能量流、信息流，实现了：

1. **系统思维**: 从设备到系统整体
2. **能量守恒**: 量化能量转换与损失
3. **故障溯源**: 追踪问题根源
4. **优化指导**: 识别节能潜力
5. **数字孪生**: 支持实时仿真
