## 概述

控制系统是机电系统的"大脑"，通过传感器采集数据、控制器执行算法、执行器调节设备，实现系统的自动运行。计量体系是"感知系统"，精确测量能源消耗，为优化提供数据基础。

## 第1层：设备控制 (Device Control)

### 1.1 启停控制 (ON/OFF Control)

**基本形式**:
```
条件A 且 条件B → 设备启动
条件C 或 条件D → 设备停止
```

**示例**: 冷冻水泵启停控制
```yaml
设备: 冷冻水泵 CHWP-001

启动条件 (ALL):
  - 冷水机组 CH-001: "运行中"
  - 系统需求: "有负荷需求"
  - 手动模式: "AUTO" (非手动强制)

停止条件 (ANY):
  - 冷水机组 CH-001: "停止"
  - 紧急停止按钮: "按下"
  - 水泵故障: "发生"

联锁逻辑:
  - 启动延迟: 30秒 (冷机运行后)
  - 停止延迟: 60秒 (冷机停止后，排出余冷)

保护:
  - 过载保护: "电流 > 110% 额定电流 → 立即停泵"
  - 低流量保护: "流量 < 50% 设计流量 → 报警"
```

### 1.2 变频控制 (VFD - Variable Frequency Drive)

**控制原理**:
```
频率 f (Hz) → 转速 n (rpm) → 流量/风量

风机/水泵相似定律:
  Q ∝ n       (流量 ∝ 转速)
  P ∝ n³      (功率 ∝ 转速³)

节能潜力: 降频 20% → 节能 48%
```

**示例**: AHU 变频控制
```yaml
设备: AHU-3F-01 (空气处理机组)
变频范围: 30 ~ 50 Hz (60% ~ 100%)

控制变量: 送风管静压
设定值: 250 Pa

控制策略:
  - 检测到静压 > 275 Pa: 频率 ↓ (降 1 Hz)
  - 检测到静压 < 225 Pa: 频率 ↑ (升 1 Hz)
  - 变化速率限制: 0.5 Hz/min (防止喘振)

下限保护:
  - 最小频率: 30 Hz (保证轴承润滑)
  - 最小风量: 60% (满足卫生要求)

节能计算:
  - 设计: 50 Hz, 45 kW
  - 实际: 40 Hz, 23 kW (节能 49%)
```

### 1.3 基本保护 (Basic Protection)

**常见保护类型**:

| 保护类型 | 保护对象 | 动作 |
|---------|---------|------|
| 过载保护 | 电机 | 电流 > 110% → 报警 > 115% → 跳闸 |
| 欠压保护 | 电气设备 | 电压 < 85% → 停车 |
| 缺相保护 | 三相电机 | 断相 → 立即跳闸 |
| 过流保护 | 变频器 | 电流 > 150% → 立即跳闸 |
| 低流量保护 | 水泵 | 流量 < 50% → 报警 |
| 低温保护 | 冷机 | 蒸发温度 < 2°C → 停车 |
| 高压保护 | 冷机 | 冷凝压力 > 2.0 MPa → 停车 |

## 第2层：回路控制 (Regulatory Control)

### 2.1 PID 控制

**PID 公式**:
```
Controller Output = Kp × e(t) + Ki × ∫e(t)dt + Kd × de(t)/dt

e(t) = Setpoint - Process Variable (偏差)
Kp: 比例增益
Ki: 积分增益
Kd: 微分增益
```

**参数整定口诀**:
```
比例作用看偏差，偏差存在就动作
积分作用看时间，积累偏差逐渐清
微分作用看趋势，提前预测快修正

整定顺序:
1. 比例 P (Kp): 从小到大，直到震荡
2. 积分 I (Ti): 消除静差，避免超调
3. 微分 D (Td): 提前调节，抑制超调
```

**示例**: 冷冻水供温度控制
```yaml
被控变量: 冷冻水供水温度
设定值: 7.0°C
测量值: T_CHW_Supply (AI-301)
控制输出: 冷机加载/卸载

PID 参数 (经验值):
  Kp: 2.0 (比例带: 0.5°C/Kp = 0.25°C)
  Ti: 300秒 (积分时间)
  Td: 0秒 (微分, 一般冷机控制不用微分)

整定过程记录:
  初始: Kp=1.0, Ti=600s → 响应慢, 静差大
  调整后: Kp=2.0, Ti=300s → 响应快, 超调小
```

### 2.2 串级控制 (Cascade Control)

**原理**: 两个 PID 控制器串联，主控制器输出作为副控制器设定值

**优势**:
- 快速抑制扰动
- 适用于大滞后系统
- 提高控制精度

**示例**: 手术室温湿度串级控制
```
主控制 (慢): 房间温度
  ↓ (设定送风温度)
副控制 (快): 送风温度
  ↓ (控制冷热水阀)

参数:
  主环: T_room (房间温度)
    Setpoint: 23°C
    Kp: 1.2
    Ti: 600s (较慢)

  副环: T_supply (送风温度)
    Setpoint: 由主环决定 (通常 16-18°C)
    Kp: 5.0
    Ti: 30s (较快)

工作原理:
  1. 房间温度偏高 (24°C > 23°C)
     → 主环输出: T_supply_setpoint = 15°C (降低送风温度)

  2. 实际送风温度 17°C > 15°C
     → 副环开启冷水阀，关闭热水阀

  3. 送风温度降至 15°C
     → 房间温度逐渐下降

隔 10分钟:
  4. 房间温度恢复 23°C
     → 主环: T_supply_setpoint = 16°C (恢复)
```

### 2.3 逻辑控制 (Logic Control)

**IF-THEN-ELSE 逻辑**

**示例**: 冷机台数控制
```
条件:
  Q_load: 实时负荷 (kW)
  Q_chiller: 单台冷机制冷量 (1055 kW)
  n_running: 运行台数

策略:
  IF Q_load > (n_running × Q_chiller × 0.9) THEN
      启动下一台冷机 (延迟 30分钟，避免频繁启停)
      n_running += 1

  IF Q_load < ((n_running - 1) × Q_chiller × 0.7) THEN
      停止一台冷机
```

**示例**: 防冻保护逻辑
```
条件:
  T_outdoor: 室外温度
  T_chw_return: 冷冻水回水温度

IF (T_outdoor < 5°C) AND (冷机停止) THEN
    启动防冻循环泵
    开启冷却塔风机 (排出余冷)
    保持水流循环
```

## 第3层：监督控制 (Supervisory Control)

### 3.1 设备调度 (Equipment Scheduling)

**目标**: 在满足需求的前提下，最小化能耗

**示例**: 冷机优化组合
```yaml
系统: 3台冷水机组，每台 1055 kW
总负荷: 2000 kW

方案1: 2台运行 (各 1000kW)
  负荷率: 1000/1055 = 95%
  效率: COP = 5.2 (高负荷效率高)
  总能耗: 2000/5.2 = 385 kW

方案2: 3台运行 (各 667kW)
  负荷率: 667/1055 = 63%
  效率: COP = 4.8 (低负荷效率略低)
  总能耗: 2000/4.8 = 417 kW

优化选择: 方案1 (节能 32 kW, 7.7%)

策略库:
  负荷 0-1000kW: 1台运行 (最高效点)
  负荷 1000-1800kW: 2台运行 (负荷率 47-85%)
  负荷 1800-3165kW: 3台运行 (负荷率 57-100%)
```

### 3.2 故障协调 (Fault Coordination)

**示例**: 冷冻水泵故障处理
```yaml
故障: CHWP-001 故障停机 (1号冷冻水泵)

自动响应:
  1. 检测故障 (电流=0, 运行信号=0)
  2. 立即启动 CHWP-002 (备用泵)
  3. 延迟 30秒，确认流量恢复

验证:
  - 流量: 恢复至 95% 以上 (成功)
  - 供水温度: 稳定 (成功)
  - 影响范围: 无 (成功)

如备用泵启动失败:
  1. 降低系统负荷:
     - 提高冷冻水设定温度 (7°C → 9°C)
     - 关闭非关键区域 (办公区)
  2. 通知运维人员紧急处理
  3. 预计修复时间 < 2小时
```

### 3.3 需求响应 (Demand Response)

**参与电网削峰填谷**

**示例**: 高峰时段 (14:00-17:00)
```
电价: 1.5元/kWh (平时 0.8元/kWh)

策略:
  1. 提前预冷 (13:00-14:00)
     - 降低冷冻水温度 (7°C → 5°C)
     - 房间温度降至 21°C
     - 储存冷量

  2. 高峰时段 (14:00-17:00)
     - 暂停一台冷机
     - 缓慢升高房间温度 (21°C → 24°C)
     - 利用建筑热惯性

  3. 经济效益
     - 节约电费: 3小时 × 185kW × (1.5-0.8) = 388元/天
     - 需评估: 舒适度影响
```

## 第4层：优化控制 (Optimization)

### 4.1 预测控制 (Predictive Control)

**机器学习预测负荷**

**示例**: 次日冷负荷预测
```yaml
输入特征:
  - 历史负荷 (过去 7天同一时间)
  - 天气预报 (温度、湿度、太阳辐射)
  - 日程安排 (门诊量、手术量)
  - 日期类型 (工作日/周末/节假日)

模型: XGBoost 回归
准确度: MAE = 8.5%, RMSE = 12%

应用:
  - 负荷预测: 2200 kW (明天 14:00)
  - 提前启动冷机: 13:30 (而不是 14:00)
  - 避免需求冲击

节能效果: 5% (避免高负荷率下的低效运行)
```

### 4.2 全局优化 (Global Optimization)

**示例**: 电费成本最小化
```yaml
优化变量:
  - x1: 冷机1负荷 (0 ~ 1055 kW)
  - x2: 冷机2负荷 (0 ~ 1055 kW)
  - x3: 冷机3负荷 (0 ~ 1055 kW)
  - y1: 水泵频率 (30 ~ 50 Hz)

目标函数:
  min Cost = Electricity_Price × (P_chiller + P_pump)

约束条件:
  - x1 + x2 + x3 = Load_Demand  (满足负荷)
  - T_supply = 7°C ± 0.5°C      (温度约束)
  - P_chiller = f(x1,x2,x3)     (能耗模型)

优化算法: 线性规划 (LP)
```

### 4.3 自适应控制 (Adaptive Control)

**自动调整 PID 参数**

**示例**: 自适应温控
```
季节调整:
  夏季: Kp=2.0, Ti=300s (响应快, 抑制超调)
  冬季: Kp=1.5, Ti=400s (响应温和, 避免频繁调节)

负荷自适应:
  负荷高 → 提高 Kp (加强调节力度)
  负荷低 → 降低 Kp (减小波动)

自学式调整:
  记录每次调节效果
  超调大 → 减小 Kp, 增加 Td
  响应慢 → 增加 Kp, 减小 Ti
```

## 计量体系 (Measurement System)

### 计量三个层级

#### 1. 一级计量 (Primary)
**计量范围**: 医院总能源消耗

**设备**:
- 总电表 (10kV 进线)
- 总水表 (市政总表)
- 总气表 (市政燃气)
- 蒸汽总表 (外购蒸汽)

**用途**: 与能源公司结算、碳排放计算

**精度要求**: 0.5% ~ 1%

#### 2. 二级计量 (Secondary)
**计量范围**: 分建筑/分系统能源消耗

**设备**:
- 建筑电表 (门诊楼、住院楼)
- 系统电表 (冷机、水泵、AHU)
- 分区水表 (空调补水、生活用水)
- 系统气表 (锅炉燃气)

**用途**: 建筑能耗分析、系统能效计算

**精度要求**: 1% ~ 2%

#### 3. 三级计量 (Tertiary)
**计量范围**: 设备/房间级计量

**设备**:
- 设备电表 (单个冷机、单台水泵)
- 房间电表 (诊室、病房)
- 末端计量 (FCU、照明、插座)

**用途**: 精准定位高能耗设备、成本分摊

**精度要求**: 2% ~ 5%

## 计量设备

### 1. 电表 (Energy Meter)

**类型**:
- 机械式电表 (已淘汰)
- 电子式电表 (主流)
- 智能电表 (带通讯)

**参数**:
```yaml
型号: DT862-4
电压: 3×220/380V
电流: 3×1.5(6)A (带 CT)
精度: Class 1
通讯: RS485 / Modbus
测量参数:
  - 有功功率 (kW)
  - 无功功率 (kVAR)
  - 功率因数
  - 频率 (Hz)
  - 有功电能 (kWh)
```

**变比 (CT 变比)**:
- 500/5: 电表乘 100 倍
- 1000/5: 电表乘 200 倍

### 2. 水表 (Water Meter)

**类型**:
- 机械式水表
- 超声波水表 (精度高, 无压损)

**参数**:
```yaml
型号: WS-50
口径: DN50
额定流量: 15 m³/h
最大流量: 30 m³/h
精度: Class B
通讯: M-Bus / Modbus
输出: 脉冲 / 4-20mA / RS485
```

### 3. 热量表 (Heat Meter)

**用于计量热能（空调水系统）**

**计算公式**:
```
Heat Energy = ∫(m × ΔT × c)dt

m: 瞬时流量 (m³/h)
ΔT: 供回水温差 (K)
c: 水的比热容 (4.1868 kJ/kg·K or 1.163 kWh/m³·K)

t = 1小时
m = 150 m³/h
ΔT = 5K
Energy = 150 × 5 × 1.163 = 872 kWh
```

**组成**:
- 流量计 (测量 m)
- 温度传感器 (测量 ΔT, 供水 & 回水)
- 积分仪 (计算 Energy)

**精度要求**: 三级（用于节能分析）

### 4. 燃气表 (Gas Meter)

**类型**:
- 皮膜式 (家用)
- 涡轮式 (工业)
- 超声波 (高精度)

**参数**:
```yaml
型号: G16
最大流量: 25 m³/h
压力: 2 ~ 50 kPa
精度: Class 1.5
通讯: RS485
温度补偿: -10°C ~ +40°C
```

## 计量数据的应用

### 1. 能效计算

**示例**: 冷机能效 COP

```
实时 COP = 制冷量 / 输入功率

制冷量 = m_chw × ΔT × 1.163
         = 150 m³/h × (12-7)K × 1.163
         = 872 kW

输入功率 = 电表读数 (kW)
         = 185 kW

COP = 872 / 185 = 4.71

设计 COP: 5.7
能效衰减: (5.7-4.71)/5.7 = 17.4%

结论: 需要检修 (COP < 0.88 × 设计值)
```

### 2. 成本分摊

**示例**: 分科室能耗成本

```
总电费: 100,000 元/月

分摊规则:
  - 公共部分: 40% (电梯、公共照明、系统设备)
  - 按面积分摊: 60%
    各科室面积 = 1000 m²
    单位面积成本 = 60,000 / 10,000 m² = 6 元/m²

内科诊室:
  面积: 200 m²
  分摊: 200 × 6 = 1200 元/月

更精准: 按三级计量
  内科诊室电表: 2500 kWh/月
  电价: 1 元/kWh
  成本: 2500 元/月 (更合理)
```

### 3. 节能验证

**示例**: 改造前后对比

```
改造前 (基准期):
  月能耗: 150,000 kWh
  月冷量: 450,000 kWh
  EER: 3.0

改造后 (验证期):
  月能耗: 120,000 kWh
  月冷量: 480,000 kWh
  EER: 4.0

节能效果:
  节能率: (150k-120k)/150k = 20%
  能效提升: (4.0-3.0)/3.0 = 33.3%

节省电费: 30,000 kWh × 1 元/kWh = 30,000 元/月
```

## 小结

控制系统实现"智能运行"，计量体系提供"数据基础"。两者结合：

1. **就地控制**: 设备级稳定运行
2. **协调控制**: 系统级优化调度
3. **预测优化**: 全系统最优运行
4. **精确计量**: 数据支撑决策

**下一步**: 基于控制和计量数据，建立故障诊断与预测性维护系统。
