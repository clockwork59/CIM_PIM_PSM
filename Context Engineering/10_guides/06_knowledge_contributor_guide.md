### 2. 运行策略贡献

**示例: 冷机群控策略**
```yaml
策略名称: "冷机台数自动优化"
适用场景: "多台冷机并联运行"

算法逻辑:
  输入:
    - 实时负荷: Q_load
    - 冷机数量: n
    - 单台容量: Q_unit

  步骤:
    1. 计算最佳台数: n_opt = ceil(Q_load / (Q_unit * 0.85))
    2. 避免频繁启停: 延迟 30 分钟再调整台数
    3. 轮换运行: 累积运行时间最少的优先启动

效果:
  - 比固定台数节能: 15-20%
  - 延长设备寿命: 磨损更均匀

贡献者: 张工 (XX医院, 10年运维经验)
验证结果: 已在3家医院实施, 效果良好
```

### 3. 故障案例贡献

**示例: 冷冻水流量不足**
```yaml
故障现象: "FCU 制冷效果差, 房间温度降不下来"

排查步骤:
  1. 检查 FCU: 风机运行正常
  2. 检查水阀: 阀门开度 100%
  3. 测量流量: 仅为设计值的 60%
  4. 检查过滤器: 过滤器前后压差大 (堵塞)
  5. 清洗过滤器: 流量恢复正常

根因: "过滤器长期未清洗, 堵塞严重"

预防措施:
  - 过滤器压差监测
  - 自动告警 (压差 > 50 kPa)
  - 每季度清洗

贡献者: 李工 (维护主管)
案例级别: 常见 (发生频率: 每季1次)
```

## 贡献流程

### 步骤 1: 识别知识

**从日常工作中发现**:
- ✅ 解决了一个棘手问题
- ✅ 优化了某个流程
- ✅ 总结了经验教训
- ✅ 发现了更好方法

**知识评估**:
- 是否具有通用性?
- 是否可复用?
- 是否对其他人有价值?

### 步骤 2: 记录整理

**记录工具**:
- CIM 贡献模板
- 手机拍照/录像 (设备铭牌、故障现象)
- 笔记本 (运行参数、操作步骤)

**整理要点**:
- 事实清晰 (时间、地点、设备、参数)
- 逻辑完整 (背景、现象、分析、解决)
- 量化数据 (能耗、时间、成本)
- 图文并茂 (照片、图表、示意图)

### 运行策略模板 (Markdown)

```markdown
# 冷机台数优化策略

## 适用场景

- 3台以上冷机并联运行
- 负荷波动范围 30%~100%

## 策略逻辑

### 变量定义

```python
Q_load = 实时冷负荷 (kW)      # 根据末端测点计算
Q_unit = 单台冷机额定制冷量 (kW)
n_max = 冷机总台数
n_running = 当前运行台数
```

### 优化算法

1. **计算最佳台数**
```python
n_optimal = math.ceil(Q_load / (Q_unit * 0.85))
# 0.85: 单台冷机最佳负荷率 (经验值)

n_optimal = min(n_optimal, n_max)
```

2. **避免频繁启停**
```python
# 检测周期: 30 分钟
detection_interval = 30 * 60  # 秒

if time_since_last_change < detection_interval:
    return  # 不调整
```

3. **容差带**
```python
# 避免在临界点反复切换
hysteresis = 0.15  # 15% 容差

# 示例: 当前 2台运行
if n_running == 2:
    if Q_load > 2 * Q_unit * (0.85 + hysteresis):
        n_target = 3  # 增到 3台
    else:
        n_target = 2  # 保持 2台

if n_running == 3:
    if Q_load < 3 * Q_unit * (0.85 - hysteresis):
        n_target = 2  # 减到 2台
    else:
        n_target = 3  # 保持 3台
```

4. **轮换运行**
```python
# 累积运行时间
total_hours = {
    'ch-001': 8500,
    'ch-002': 9200,
    'ch-003': 7800,
}

# 优先启动运行时间最短的
if n_optimal > n_running:
    idle_chillers = get_idle_chillers()
    next_start = min(idle_chillers, key=lambda x: total_hours[x])
    start(next_start)

# 优先停止运行时间最长的
if n_optimal < n_running:
    running_chillers = get_running_chillers()
    next_stop = max(running_chillers, key=lambda x: total_hours[x])
    stop(next_stop)
```

### 实施效果

| 策略 | 平均台数 | 平均负荷率 | 日能耗 |
|-----|---------|-----------|--------|
| 固定3台 | 3.0 | 62% | 4,850 kWh |
| 优化策略 | 2.3 | 81% | 4,120 kWh |
| **节约** | - | - | **730 kWh (15%)** |

### 注意事项

- **最小运行时间**: 单台冷机启动后，至少运行 60 分钟再停 (保护压缩机)
- **冷却水温度**: 低负荷时，注意冷却水温度不能过低 (防止喘振)
- **管网平衡**: 减少台数后，检查末端水力平衡 (避免流量不足)
